# Sling Battle 3D

自キャラそのものを引っ張って(スリングショットのように)離すと発射され、
壁や敵に跳ね返りながら敵を弾き飛ばしていく——という操作感を検証するための
Three.js製アリーナバトルです。スマホ縦画面・片手操作に特化しています。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/sling-battle-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- **自キャラ(青い球)にタッチして引っ張り**、指を離すと引っ張った方向と逆向きに発射される
  (パチンコ・スリングショットのイメージ)
- 引っ張る距離が長いほど発射速度が上がる(黄色→赤色に変化する線で威力を表示)
- 発射された自キャラは壁で跳ね返りながら飛び続け、敵に当たるとダメージを与えて跳ね返る
- **1回の発射中に連続で敵にヒットさせるとコンボ**になり、ダメージが増加していく
  (壁で跳ね返って同じ敵にもう一度当てるのもコンボに含まれる)
- 自キャラが完全に停止すると、生き残っている敵が1歩ずつ近づいてくる。
  接触しているとダメージを受ける(自キャラのHPが0でゲームオーバー)
- 敵を全滅させればクリア

## 仕組みメモ

- 引っ張り操作は画面上のタッチ座標をレイキャストで床面(Y=0)へ投影し、
  ワールド座標で扱っている(カメラの角度に関わらず正確に引っ張り量を計算できる)
- 物理・当たり判定はDOM/Three.jsから独立した純粋関数にしている
  - `computeLaunchVelocity` — 引っ張りベクトルから発射速度・方向を算出(弱すぎる引っ張りはキャンセル扱い)
  - `bounceOffWalls` — アリーナの壁との反射
  - `reflectOffCircle` — 敵との弾性衝突による反射(進入角度に応じた反射)
  - `computeImpactDamage` — 衝突速度とコンボ数からダメージを算出
  - `advanceToward` — 敵ターンでの1歩分の接近移動
- 同じ敵に連続で当たり判定が発生しないよう「重なり始めた瞬間」だけ判定するエッジトリガー方式。
  一度離れてから再度当たれば(壁バウンドからの再ヒットなど)コンボとして再判定される
- 自キャラは発射のたびに元の位置へ戻るのではなく、**停止した場所がそのまま次の引っ張りの起点**になる
  (本家スリングアクションゲームと同様、位置取りが次の一手に影響する)
- 敵ターンは見た目のテンポのための固定時間の間だけ待つのみで、実際の移動・ダメージ計算は
  ターン開始時に即座に確定している(判定自体はフレームレートに依存しない)
