# China Walk TPS

中華風の女性キャラクター(`assets/china_rigged.glb`、リグ入り)が、暗い空間(倉庫風の部屋)を歩く
スマホ縦画面・TPS(三人称)視点のデモです。Three.js製。

## 遊び方

```bash
cd games/china-walk-tps
python3 -m http.server 8080
# http://localhost:8080 を開く(スマホなら同じWi-FiでPCのIPの8080番)
```

- **画面の左半分をドラッグ**: 歩く(押した場所に仮想スティックが出る。カメラの向きを基準に歩く)
- **画面の右半分をドラッグ**: 視点(カメラ)の回転
- PC: **WASD / 矢印キー** で移動、**マウスドラッグ** で視点

## 仕組み

- 歩きのモーションは `assets/walk.json`(humanoid-gltf-exporterで作成した、その場歩き・1秒1サイクル・歩幅0.9m)。
  移動速度に合わせて再生速度を変えるので、足が滑らない。止まると、歩きの中の「両足がそろう」姿勢(立ち姿)へなじむ
- **当たり判定**: 部屋の真ん中の柱(半径0.8m)と木箱4つは「円」、壁は四角で判定。キャラ(半径0.3m)は
  すり抜けず、柱に当たったら滑って回り込む。1回の移動を最大0.1mに刻んでいるので、速くても抜けない
- **カメラ**: キャラの背後(距離3.4m)。柱・箱・壁にめり込みそうなときは自動で手前に寄る
- テクスチャ(コンクリート・波板の壁・柱・注意帯)はすべてコードで生成(画像ファイルなし)

### テスト結果 (Playwright)
- 柱へまっすぐ歩く → 柱の中心から1.100m(= 0.8 + 0.3)でぴったり止まる
- 柱に押しつけたまま横へ入力 → 柱に沿って回り込む
- 20方向から柱へ3.4秒ずつ突入 → 最短1.100m(すり抜けなし)／壁際は±6.7mで止まる
- 実タッチ(左ドラッグで歩く・右ドラッグで視点)で動作、エラーなし
