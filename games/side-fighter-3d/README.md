# Side Fighter 3D

鉄拳のようなサイドビュー視点の3D格闘ゲームの、第1段階です(Three.js製)。

- 左: **中華娘**(プレイヤー) / 右: **USAボクサー**(CPU) が向かい合って立つ
- スマホ縦画面向け。**画面の左右スワイプ(ドラッグ)で横(X軸)、上下スワイプで奥(上)・手前(下)(Z軸)へ移動**する。斜めも可
  - 押した位置から動かした量で、移動の向きと速さが決まる。離すと止まる
  - 右(CPUの方)へ動くと前進(歩きの順再生)、左へ動くと後退(歩きの逆再生)
  - PCでは A/D(←/→)で左右、W/S(↑/↓)で奥/手前
- **タップで攻撃**: 画面の**左半分をタップ = 左ジャブ**(踏み込みあり)、**右半分をタップ = 右ローキック**(PCは J / K キー、マウスのクリックも可)
  - ほとんど動かさず(12px以内)すぐ離す(0.32秒以内)とタップ。スワイプ(ドラッグ)で動かしたあとは攻撃にならない
  - 攻撃中は移動も次の攻撃もできない(連打は無視)。攻撃モーションは `assets/leftPunch1.json` / `assets/rightLowKick.json`(再生速度 `ATTACK_SPEED` = 1.3倍)
- CPUは自分で動いて攻撃してくる(下の「CPUのAI」)。体力ゲージはなく、攻撃を受けると**ノックバック**で押され、**場外へ出れば負け**

## 遊び方

```bash
cd games/side-fighter-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

## 仕組みメモ

- 座標: X軸が左右(右が+)、Yが上。カメラは+Z側から真横にステージを見る。モデルは+Zを向いているので、
  プレイヤーは+90°(右向き)、CPUは-90°(左向き)に回して配置
- **カメラ**: 画面に映すステージ幅(`VISIBLE_WIDTH` = 3.5m)が、縦画面でも横画面でも収まる距離に置く。2人の中間のXを、なめらかに追う
- **移動の制限**: ステージの端(±2.6m)/CPUに食い込まない(`BODY_GAP` = 0.7m)/CPUから離れすぎない(`MAX_GAP` = 2.4m。両方が画面に映るように)
- **モーション**: 構えは `fightIdleUsa.json`(2人とも)。移動は下の「フットワーク」(ファイティングポーズのままステップ)
- **ステージ(簡易)**: 暗い石畳の床、奥の赤い壁、柱とランプ。テクスチャはすべてコードで生成

### テスト結果 (Playwright)
- 左ドラッグで後退(-0.8 → -1.6 で止まる=CPUから2.4m)/右ドラッグで前進(CPUから0.700mで止まる=食い込まない)/縦ドラッグは無視/離すと止まる
- エラーなし

### 攻撃のテスト結果 (Playwright)
- 左タップ→左ジャブ(約1.1秒)、右タップ→右ローキック(約0.8秒)。腕が伸びる・足が上がる姿勢を撮影で確認
- 攻撃中の2回目のタップは無視／ドラッグして離しても攻撃にならない／攻撃中は移動できない／エラーなし

## 奥・手前(Z軸)の移動
- 上にスワイプ=奥(-Z)、下にスワイプ=手前(+Z)。ステージの奥行きは ±1.0m（`STAGE_Z`）。斜めに動かせば X と Z を同時に動く
- 2人は常にお互いを向く（体の向きをなめらかに回す）。CPUからの距離は2Dで判定: 0.7m以内に食い込まない／2.4m以上は離れない（円どうしの押し出し）
- 移動のアニメ: 下の「フットワーク」を参照
- 攻撃の踏み込みも、CPUのいる方向へ。攻撃はどの位置からも出せる
- テスト: 上ドラッグで奥の端(-1.00)、下ドラッグで手前の端(+1.00)で止まる／斜めでCPUに近づいても2D距離≥0.7／斜めで離れても≤2.4／体の向きがCPUを向く／移動後も攻撃できる／エラーなし

## リングアウト（場外に出たら負け）とカメラの引き
- ステージは**四角い台（リング）**（一辺 6.8m = `RING_HALF` 3.4m の半分。以前の円形・直径5mより大きい）。縁の外は深い闇。四辺とも、金色のラインが縁
- 体の中心が縁より外（`RING_OUT_MARGIN` = 0.1m 以上、X・Zのうちいちばん外へ出ている軸で判定。角も同じ）へ出たら**リングアウト = 負け**。負けた側は縁から外へ放り出され、回転しながら落ちる。約1.4秒後に「RING OUT!」と「YOU LOSE」(CPUが落ちたら「YOU WIN!」)＋「もう一度」ボタン。以降は操作できない
- 以前の「離れすぎない」制限（`MAX_GAP`）と、ステージの端での停止はなくした（縁の外へ自分で出られる）。CPUへの食い込み防止（0.7m）は残してある
- **カメラ**: 映す幅 = 2人の間隔 + 余白(2.4m)。幅は最小3.5m〜最大10mで、離れるほど遠く・広く映し、近づくとまた寄る（なめらかに追従）。左右の中間を追う点は同じ
- テスト: 縁の内側2.40mではリングアウトにならない／2.65mで負け／奥・手前（z=2.7）でも判定／CPUが落ちると「YOU WIN!」／離れると映す幅が 4.0 → 4.6 → 5.8m と広がる／試合後は操作・攻撃を受け付けない／エラーなし

### リングを四角・大きく（更新）
- 円形（半径2.5m）→ **四角（一辺 6.8m）**に変更。台は箱型、縁のラインは四辺。判定は `max(|x|, |z|) > RING_HALF + 0.1`
- テスト: 辺の内側3.3m は4方向・角ともリングアウトなし／外側3.55m は4方向・角ともリングアウト／以前の円では外だった x=-2.8 でも落ちない／エラーなし

## 上段・中段・下段の使い分け（更新）
- **画面の右半分をタップ**で攻撃（左半分は攻撃なし。スワイプでの移動は画面のどこでも可）。**タップした画面の高さ**で技を使い分ける:
  - **上段**: キャラの頭より上（頭の上端から、体の高さの20%より上）をタップ → 左ジャブ（`leftPunch1.json`）
  - **中段**: キャラの体のあたり（頭〜足元の手前）をタップ → 右ストレート（`rightStraight.json`）
  - **下段**: 足元より下（足元から体の高さの10%より上は中段）をタップ → 右ローキック（`rightLowKick.json`）
- 高さの基準は、プレイヤーの頭・足元の**画面上の位置**（カメラの寄り・引き、奥・手前に合わせて毎回計算）
- 画面の左側に、うすい点線（境目）と「上段／中段／下段」の目印を表示。タップしたゾーンは一瞬光る
- PCは J=上段 / K=中段 / L=下段
- 現状は「技の種類」を高さで選ぶだけで、当たり判定（相手の頭・胸・足に当てる）はまだない
- テスト: 頭より上・画面上端 → 上段／頭の高さ・胴体・足首 → 中段／足元・台の側面 → 下段／右半分のタップ → 何も起きない／エラーなし

## 攻撃の当たり判定とCPUのリアクション（更新）
- **攻撃の領域を右半分に変更**。上段・中段・下段の目印は画面の右側に表示
- **当たり判定**: 攻撃の振り出し〜伸びきり（攻撃の長さの15〜72%）の間、攻撃している手足（上段=左拳、中段=右拳、下段=右足。拳は手首から少し先、半径0.16〜0.2m）と、CPUの体の球（頭0.2・胸0.3・腹0.27・両すね0.19m）が重なったらヒット。1回の攻撃で1回。距離が遠い（2.4m）と当たらない
- **CPUのリアクション**（攻撃の高さに合わせる）: 上段=頭がのけぞる／中段=体がくの字に折れる／下段=膝が崩れる。ヒットの瞬間に一瞬白く光る
- **ノックバック**: ヒットするとCPUが攻撃の向きへ押される（ジャブ0.45m・ストレート0.7m・ローキック0.55m）。**場外まで押し出せばリングアウト=勝ち**
- テスト: 左半分のタップは何も起きず右半分で攻撃／3種類とも近距離でヒット・ノックバック量どおり／遠距離は0ヒット／縁の近くでストレート → CPUが場外へ → 「YOU WIN!」／エラーなし

## CPUのAIと攻撃（飛び込み3種）
- **状態**: `idle`(構えて様子見) → `approach`(間合い1.5〜1.95mまで歩いて近づく。Zもプレイヤーに合わせる) → `windup`(予備動作) → `attack`(飛び込み) → `recover`(隙 0.45〜0.8秒) → `idle` / `retreat`(40%で後ろへ0.6〜1.1m下がる)
- **技**（同じ技が3回続かないよう、重み 上段40・中段35・下段25）:
  - **上段 飛び込み左リードジャブ**: 予備動作0.42秒（のけぞって左拳を引く）→ 飛び込んで左ジャブ（`assets/cpuJab.json` = USAボクサーの左ジャブ）
  - **中段 飛び込み右ボディストレート**: 予備動作0.48秒（腰を落として低く構える）→ 低い姿勢のまま飛び込み、右ストレートを胴へ（`assets/cpuBodyStraight.json` = 右ストレートに低い姿勢を重ねて作成）
  - **下段 飛び込み右フック（足狩り）**: 予備動作0.54秒（深く沈み、右腕を外へ引く）→ 低く飛び込み、右腕を低く振って足を刈る（`assets/cpuLowHook.json` = 新規作成）
- **飛び込み**: CPUの位置そのものを前へ動かす（攻撃が終わっても元に戻らない）。**向きと距離は予備動作の「はじめ」に確定**し、体の向きも固定する → 予備動作を見てから**後ろへ下がる／Z軸（奥・手前）へ横ステップ**すればかわせる。リングの外へは自分から飛び出さない
- **プレイヤーへの当たり判定**: CPUの手の球（0.15〜0.3m）× プレイヤーの体の球（頭・胸・腹・もも・すね。CPUへの判定よりひとまわり小さい）。ヒットすると、プレイヤーが**のけぞり**（上段=頭／中段=体が折れる／下段=膝が崩れる）、**ノックバック**（0.5〜0.7m）、約0.5秒の**硬直**（動けない・攻撃できない）、体が一瞬光る。攻撃中なら中断される
- **カウンター**: CPUの予備動作・攻撃中にプレイヤーの攻撃を当てると、CPUの攻撃は中断（硬直0.45秒）
- テスト(Playwright): 立っているプレイヤーに3種とも当たる（各6/6）／予備動作を見て後ろへ下がる・Z軸へ横ステップするとどの技もかわせる／攻撃でCPUの攻撃を潰せる／放置すると、CPUが近づく→予備動作→飛び込み→ヒット→ノックバックを繰り返し、場外でリングアウト負け／エラーなし
- 注意: CPUは右を向いて立つとき、右腕がカメラの反対側になるため、右ボディストレート・右フックの腕は体に隠れて見えにくい（体の沈み込みと飛び込みで判断できる）

## フットワーク（ファイティングポーズを保ったままステップで移動）
- プレイヤーもCPUも、移動中も**上半身は構えのまま**（腕・ガード・頭はアイドルのまま）。**脚だけ**をボクサーのシャッフル（軽いステップ）に差し替える。以前の「歩き」は廃止（`walk.json` は削除）
- 新規モーション（`fightIdleUsa.json` の構えを土台に、脚だけ作成。1サイクル0.67秒、ループ）:
  - `assets/stepForward.json`: 前後のステップ。**相手へ近づく=順再生、離れる=逆再生**。1サイクル(左右1歩ずつ)で0.8m進む。足を引き上げて前へ出し、接地中は後ろへ流れる。わずかな上下の揺れ
  - `assets/stepSide.json`: 横(奥・手前)のステップ。キャラの右へ=そのまま、左へ=左右反転。1サイクル0.6m
- 前後と横の動きが混ざる斜め移動は、2つを動きの割合でブレンド。再生は動いた距離に合わせる（足が滑らない）。ステップの強さは速さに応じてなめらかに変化。CPUは攻撃の予備動作・攻撃中はステップしない
- 攻撃・のけぞり・ダウンなどは、これまでどおり構えの上に重ねる
- `?ai=0` を付けて開くと、CPUが自分からは攻撃しない（練習・動作確認用）
- テスト: 前進・後退・奥手前の3方向で、構えを保ったまま脚が動くことを撮影で確認／攻撃・当たり判定・CPUのAI・かわし(後ろ/横ステップ)の既存テストは変化なし／エラーなし

## モーションのキーフレーム数（編集しやすいよう、少なく）
- 1つの技・動きは、**基本5〜10キーフレーム以内**に減らした（`tools/reduce_keyframes.py` で、元の動きからのずれが最小になるフレームを選んで残す）。減らす前のファイルは git の履歴にある
- 結果（キー数 / 元の動きとの最大ずれ）: `leftPunch1`(上段・左ジャブ) 45→**10** (17°) ／ `rightLowKick`(下段) 33→**10** (21°) ／ `rightStraight`(中段) **8**（元のまま）／ `cpuJab` **6**（元のまま）／ `cpuBodyStraight` 21→**9** (3.7°) ／ `cpuLowHook` 20→**9** (6.5°) ／ `stepForward` 21→**7** (6.2°) ／ `stepSide` 21→**7** (4.6°) ／ `fightIdleUsa`(構え) 11→**6** (2.5°)
- 攻撃のモーション(`leftPunch1`・`rightLowKick`)は、末尾の「構えに戻って止まっている」部分も切り落とした（最後のキー = 動きの終わり）。ゲームでの長さ・当たり判定のタイミングは変わらない
- 使い方: `python3 tools/reduce_keyframes.py assets/foo.json --keys 5 --max-keys 10 --tol 0.06 [--trim-tail]`

## 距離で技が変わる（近接 / 遠間）
- 右側タップの高さ（上段・中段・下段）に加えて、**タップした瞬間の相手との距離**で技が変わる。境目は `NEAR_DIST = 1.4`（2人の中心の距離, m）。`main.js` の `ATTACKS` の表で定義（`hit` = 当たる区間、`lunge` = 前へ踏み込む区間と距離）
- 近接（1.4m未満）: 上段 **右後ろ回し蹴り**（`rightBackSpinKick`） / 中段 **左ジャブ**（`leftPunch1`） / 下段 右ローキック（`rightLowKick`）
- 遠間（1.4m以上）: 上段 **右飛び後ろ回し蹴り**（`rightFlyingBackSpinKick`） / 中段 **飛び込み左サイドキック**（`leftLungeSideKick`） / 下段 **左スライドローキック**（`leftSlideLowKick1`）。遠間の技は、実際に前へ踏み込む（CPUの手前で止まる）ので、空振りすると隙になる
- 新しい4技のキーフレームは各8個。`rightStraight`（右ストレート）は今は使っていない
