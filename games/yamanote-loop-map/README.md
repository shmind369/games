# 山手線ループマップ

JR山手線の実在する30駅をループ状の「壁」として配置し、その内側を自由に歩き回れる、
RPG用のフィールドマップです。素の2D Canvasで実装しています。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/yamanote-loop-map
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 画面上の**好きな場所をドラッグ**するとバーチャルスティックが出現し、
  引っ張った方向にキャラクターが移動する(指を離すと停止)
- 山手線の内側の円形エリアが移動可能範囲。駅の並び(壁)を越えて外には出られない
- 画面上部に、現在キャラクターが一番近づいている駅名を表示する

## 仕組みメモ

- 30駅は「巣鴨」を先頭(12時の位置)に、実際の山手線の順番通り時計回りに等間隔で配置している
- 座標計算はDOM/Canvasから独立した純粋関数にしている
  - `angleForStationIndex` / `stationPosition` — 駅のインデックスから円周上の座標を算出
  - `nearestStationIndex` — プレイヤーの現在位置から一番近い駅を算出
  - `clampToCircle` — 円形の移動可能範囲にプレイヤー座標をクランプ
  - `computeJoystickVector` — バーチャルスティックの入力ベクトルを最大半径内にクランプ
- 移動は画面のどこでも指を置いた位置を起点にしたバーチャルスティック方式(アナログ入力)。
  4方向スナップはせず、任意の角度に移動できる
- 駅ラベルは29駅分を一度に表示すると密集しすぎるため、偶数・奇数番目で表示距離を
  ずらして重なりを軽減している
