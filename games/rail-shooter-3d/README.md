# Rail Shooter 3D

Three.js製の疑似3D「奥スクロール」ガンシューティングです。ファミコン時代のアクションゲームにあった、
偶数面のような構成 — プレイヤーキャラを背後から見た視点で、画面奥に向かって自動的に進みながら、
迫ってくる敵やタレット、レーザーゲートを撃ち抜いていくステージを1本、スマホ縦画面・片手操作に
特化して作りました。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/rail-shooter-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 前進は自動。プレイヤーが操作するのは**左右移動と射撃**のみ
- **画面をドラッグ**で左右移動(レーンの範囲内でクランプ)
- **画面をタップ**(素早く指を離す)で射撃。タップした場所に近い敵を自動で狙い撃ち
- 画面上部のバーがステージ進行度。最後まで到達すると「STAGE CLEAR」

## 敵・障害物の種類

- **敵兵(赤)**: 奥から近づいてくる。プレイヤーに到達する前に撃たなければ接触ダメージ
- **タレット(灰色)**: 画面左右に固定で出現し、一定間隔でプレイヤーの現在地を狙って弾を発射する。
  弾が着弾するまでに横移動すれば回避可能。タレット自体も撃って破壊できる
- **レーザーゲート(赤いバー)**: 撃っても壊せない障害物。ゲートには隙間があり、
  ゲートが到達する瞬間にその隙間の中にいなければダメージを受ける

HPが0になるとゲームオーバー(タップで再挑戦)。

## 仕組みメモ

- 実際にカメラやプレイヤーが前進するのではなく、敵・タレット・ゲート・装飾用の柱が
  すべて同じ速度でプレイヤー側(+Z方向)へ移動する「ワールドが流れてくる」方式にしている。
  これによりステージ進行度や当たり判定が距離ベースで単純化でき、フレームレートに依存しない
- 当たり判定・命中判定はDOM/Three.jsから独立した純粋関数にしている
  - `clampLaneX` — 左右移動範囲のクランプ
  - `pickTarget` — タップ座標と敵のスクリーン座標から最も近い命中対象を選ぶ
  - `isInGateGap` — レーザーゲートの隙間判定
  - `isProjectileHit` — タレット弾の着弾判定
- 敵・タレット・ゲートはいずれも「プレイヤー地点に到達した瞬間」だけ判定するエッジトリガー方式
  (bump-combat-prototypeで採用したものと同じ考え方)
- タップとドラッグは、指を置いてからの移動距離と経過時間で判別している
  (小さく素早い操作は射撃、一定以上動かせば左右移動のドラッグ)
- 地面はテクスチャのオフセットをスクロール速度に応じて動かすことで表現しており、
  実際にジオメトリを動かしていないため軽量
