# RUBBER LINK(プロトタイプ)

伸縮するゴム紐とアンカーを利用して、ステージ内を自由自在に移動する2D物理アクションゲームのプロトタイプです。
キャラクターは四角形で代用し、物理挙動とタッチ操作の手触りを優先しています。

## 操作

| 操作 | 内容 |
| --- | --- |
| パッド(左下) | 左右に倒して歩く。上に弾くとジャンプ。ぶら下がり中は左右で振り子をこぐ |
| タップ(非接続時) | タップ方向へアンカーを発射。ブロックに当たるとゴム紐で接続(少しだけエイム補正あり) |
| ドラッグ(接続中) | 四角を引っ張ってゴムを伸ばす。指を離すと反動で飛び出す |
| タップ(接続中) | アンカー解除 |
| ▲ / ▼ 長押し | ゴムの自然長を縮める / 伸ばす(振り子の加速・登り降り) |
| PC | A・D(←→)で移動、W(↑)でジャンプ、クリック/ドラッグ、Z・Xで伸縮、Spaceで解除、Rでリトライ |

斜線入りの金属ブロック(外壁など)にはアンカーが刺さりません。

## 物理モデル

- 重力・空気抵抗・半陰的オイラー積分(1/240秒固定サブステップ)
- ゴム紐: 自然長より伸びた時だけ働くばね(フック則)+ 伸縮速度に比例する減衰。たるんでいる時は力ゼロ
- ドラッグ: 指位置へ臨界減衰ばねで引き寄せ、自然長+最大ストレッチまでに制限
- 壁・床: AABBの軸分離衝突、反発係数、接地時の摩擦
- 「調整」ボタンから各パラメータを実行中に変更可能
