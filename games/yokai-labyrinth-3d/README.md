# yokai-labyrinth-3d(旅の冒険者 ― 妖怪迷宮)

主人公「旅の冒険者」のデザイン画をもとにした、和風のターン制ローグライク(Three.js製、ボクセル表現)。
1マスずつ動くと妖怪も1回動く。階段を降りていき、地下10階に眠る「龍の宝玉」を手に入れたらクリア。倒れたら最初からやり直し。

## 操作
- 画面の十字ボタン(8方向): 移動・攻撃(押しっぱなしで連続移動。妖怪が見えたり道具を拾ったりすると止まる)
- 足踏み: 1ターン待つ(HPが少し早く回復)
- 道具: 旅袋を開く(食べる/飲む/読む/装備/投げる/置く)
- 投げる: 手裏剣を投げる(一直線上に見えている妖怪がいれば自動でそちらを狙う)
- 足元: 階段を降りる/足元の道具を拾う
- 視点: カメラの寄り・引きを切り替え
- 地図(右上)タップ: 拡大
- PC: 矢印/WASD で移動、QEZC で斜め、Shift+方向で向きだけ変える、Space 足踏み、I 道具、T 投げる、Enter 足元、M 地図、V 視点

## デザイン画からの反映
- 主人公: 黒髪のツンツン頭と赤い髪紐の髷、紺の羽織(袖口の市松模様)、赤い襟巻き、生成りの袴、脚絆と下駄、寝ござを巻いた背負い袋、腰の瓢箪と刀
- 表情バリエーション(通常・驚き・笑顔・気合): 左上の顔グラフィックが状況で切り替わる(被弾/妖怪発見で驚き、拾得/レベルアップで笑顔、攻撃やHPが少ないときは気合)
- 初期装備: 旅の刀・旅笠・水筒(+おにぎり・薬草)。旅袋が道具袋(12個まで)
- カラーバリエーション: タイトル画面で羽織の色(青・赤・緑・白・黒)を選べる

## 中身
- 迷宮: 3×3の区画に部屋と通路を毎回ランダム生成。部屋の中では部屋全体、通路では周囲1マスだけ見える
- 階層: 1〜3F 竹林の洞 / 4〜6F 古寺の回廊 / 7〜9F 鬼ヶ砦 / 10F 奥の院(鬼の大将が宝玉を守る)
- 妖怪: 鬼火・一つ目小僧・河童・唐傘おばけ・天狗(1ターンに2回動く)・赤鬼・鬼の大将
- 道具: おにぎり/大きなおにぎり、薬草、霊薬、水筒、火遁・金縛り・千里眼の巻物、手裏剣、刀(脇差・打刀・名刀「朧月」)、笠(鉄笠・陣笠・鬼面の兜)、銭
- 満腹度(0になるとHPが減る)、レベルアップ、HP自然回復、最高到達階の記録(ブラウザに保存)
