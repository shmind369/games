# 世界史閲覧

西暦を入力すると、その年の世界各地の状況が一覧できる歴史ビューアです。
「1582年って、世界では何が起きていたんだ？」から「そのとき信長は？
家康は？ヨーロッパでは？」と、年を移動しながら歴史を探索できることを
目的にしています。ゲームではなく、Three.js等も使わない素のHTML/CSS/JS製
の単一ページアプリです。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/world-history-viewer
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 上部の年号を直接編集して**Enter**、または**←/→**ボタンで1年ずつ、
  **10年前/10年後**ボタンで10年ずつ移動できる
- 現在表示中の年はURLの`?year=`に反映されるので、そのままリンクとして
  共有できる(「🔗 この年を共有」ボタンでクリップボードにコピー)
- 地域(日本・中国・ヨーロッパ・中東)ごとにカードで時代区分と主要人物を
  表示。人物カードをタップすると、生涯タイムライン(現在の年をハイライト)
  を表示する詳細画面が開く
- 「この年に生きていた人物」一覧は年齢順/地域順に並べ替え、年代
  (10代以下・20代…)で絞り込みができる
- データのない年に移動しても、時代区分(大分類含む)は常に表示され、
  「記録はまだありません」という空状態を出すだけでクラッシュしない

## 実装メモ

データとロジックとUIを分離している。

- `data.json` — `people`(人物)・`events`(出来事)・`eras`(地域ごとの
  時代区分)の3配列のみのプレーンなデータ。後から人物・出来事を追記する
  だけで内容を拡充できる。`events`は「世界の出来事」と「人物の生涯の
  節目」を区別せず同じ配列で表現しており、`people`フィールドに人物IDを
  含めることで、人物の詳細タイムラインは単に「その人物を含むイベントを
  年代順に並べたもの」として自然に導出される
- `history.js` — `data.json`を読み込んで問い合わせるDOM非依存の純粋
  関数群(年齢計算、在命者抽出、年別イベント抽出、地域別グルーピング、
  時代区分の特定、年代バケット分類など)。Node上で直接動作確認できる
- `main.js` — `history.js`の関数を使って画面を組み立てる薄い描画層。
  年の状態管理、URL同期、人物詳細オーバーレイの開閉を担当

### 年齢の扱い

`birthYear`(必須)と`deathYear`から`検索年 - 生年`で年齢を算出する
(アプリの検索粒度が「年」単位のため、正確な誕生日は考慮しない一般的な
数え方)。`approx: true`が付いた人物(生年に諸説がある場合など)は
「約48歳」のように約数表記になる。生年より前・没年より後の年を検索
した場合はその人物自体が一覧に出てこない。

### 時代区分

`eras`は地域(`region`)ごとの`startYear`〜`endYear`(開始年を含み終了年を
含まない)と、`古代/中世/近世/近代/現代`の大分類`period`を持つ。同じ地域・
年に複数の時代区分が該当する場合は、最も期間の短い(＝最も具体的な)もの
を優先する。これを利用して、明朝という大きな時代区分の中に「万暦」という
元号年間だけの短い区間を重ねて登録し、`明・万暦10年`のような元号年表記を
実現している(`reignStartYear`を持つ時代区分だけがこの元号年計算の対象)。
大分類(古代/中世/…)は、地域を問わず日本の時代区分テーブルを基準に算出
している(先史時代まで切れ目なく網羅しているため)。

### サンプルデータ

初期表示の1582年を中心に、織田信長・豊臣秀吉・徳川家康・明智光秀・
エリザベス1世・フェリペ2世・万暦帝・張居正・ムラト3世の生涯の節目を
収録している。信長ら3名は1534〜1616年の間、実際に年号を動かしながら
探索できるだけの分量のイベントを持たせてある。
