# school-walk-3d

手描きの1階間取り図をもとに作った学校を、一人称視点で歩き回れるウォークスルー(Three.js製、スマホ縦画面向け)。

## 操作
- 画面左下をドラッグ: 移動(大きく倒すと走る)
- それ以外の場所をドラッグ: 見回す
- 右上の地図をタップ: 地図の拡大/縮小
- PC: WASD / 矢印キー + マウスドラッグ(Shiftで走る)

## 間取りの編集
`main.js` 冒頭の `rooms`(部屋の矩形・名前・種類・窓のある辺)と `openings`(戸・開口部)に、
間取り図のピクセル座標をそのまま書いています(1px = 0.045m)。部屋名や戸の位置はここを書き換えれば反映されます。
