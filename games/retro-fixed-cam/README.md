# Fixed Cam Walk（初代バイオハザード風の固定カメラ ＋ ラジコン操作）

**写真を背景にした固定カメラ（2シーン）**の中を、**中華娘（3Dモデル）**が**ラジコン操作**（初代バイオハザードの「タンクコントロール」）で歩く試作。写真の床・壁・障害物に合わせて、キャラが**矛盾なく**（大きさ・遠近・当たり判定・手前の物に隠れる）動く。

- 開く: `index.html`（ネット接続不要）。写真は `assets/hall1.jpg`（廊下の手前と階段）と `assets/hall2.jpg`（廊下の奥）
- 操作: **▲ 前進 / ▼ 後退 / ◀ 左旋回 / ▶ 右旋回**（旋回はその場で回る）。**走る** = 押しながら前進。キーボード: 矢印（または WASD）、Shift で走る。右上の **「検出結果」** で、床の範囲（緑）・障害物（赤）・0.5m格子・手前に隠す物の輪郭（黄の破線）を写真の上に重ねて確認できる

## どうやって「写真と矛盾なく」動かしているか
1. **カメラの復元**（`tools/calibrate.py`）: 写真の「床と壁の境目」の線を2本（左の襖の下・右の壁の巾木）指定 → 交点が廊下の奥行き方向の**消失点** → カメラの上下の傾き・横の向きがわかる。画角は iPhone 標準カメラ（26mm相当）を仮定、廊下の幅（1.8m と見積もり）から**カメラの高さ（約1.65m）**を求める。これで「写真の1画素 ⇔ 床の1点（メートル）」が相互に変換できる
2. **3Dのカメラを写真のカメラに合わせる**: 位置・向き・画角を一致させるので、床の上のキャラは、写真の遠近どおりの大きさ・向きで描かれる（奥へ行くほど小さくなる）
3. **床と障害物**: 歩ける範囲（床の多角形）と障害物（右の爪とぎ・親柱・左の段ボールのかたまり・階段の手前の縁）を、床のメートル座標で持つ（`assets/scene1.json` / `scene2.json`）。キャラは体の半径 0.2m で当たり判定し、壁にぶつかったら**壁にそって滑る**。ランダムに300回歩かせて、常に歩ける範囲の中にいることを確認した
4. **手前の物に隠れる**（オクルージョン）: 親柱（と巻きついた段ボール）の輪郭で写真を切り抜いて、キャラの上に重ねる。キャラが柱より**奥**にいるときだけ重ねるので、柱の後ろに回ると隠れ、手前では隠れない
5. **ラジコン操作**: 向き θ を左右で回し、前後は向いている方向へ進む。足の動き（歩き）は進んだ距離に合わせて再生する（壁にぶつかって進めないときは止まる）

## 「写真から床・壁・障害物を自動で検出」について（正直なところ）
- この試作では、**線・床の範囲・障害物・手前の物の輪郭の点は、この写真を見て私が指定したもの**（`tools/calibrate.py` の定数）。**自動検出ではない**。別の写真に使うときは、定数を書き換えて `python3 tools/calibrate.py` を実行する（`assets/scene1.json` / `scene2.json` が作り直される）
- 自動検出も、方向としては可能: 線の検出（Hough変換）で消失点を求める／セグメンテーション（床・壁の領域分け）／単眼の深度推定モデルで、床の範囲と障害物を出す。ただし、AIモデルが必要（この環境では実行していない）で、精度は写真しだいなので、手で直せる形（この `tools/calibrate.py`）を土台にして、段階的に自動化するのが現実的
- 誤差の目安: 画角・廊下の幅・点の位置は見積もりなので、キャラの大きさや足元は数%〜1割ほどずれることがある。「検出結果」の表示と見比べて、`tools/calibrate.py` の `F`（焦点距離）・`WIDTH_M`（廊下の幅）・点を調整する

## シーンの切り替え（固定カメラのカット）
- **シーン1（廊下の手前・階段）の、廊下の奥の机のそば（床 Z 3.82m〜。ふつうに奥まで歩くと着く位置）** まで歩くと、黒いフェードを挟んで、**シーン2（廊下の奥）の、右下の机のそば**（床 X 1.11m, Z 2.19m）に、**左（-X）向き（向き 271°）**で切り替わる。シーン1の机のそばに立つ位置 → シーン2の同じ机のそばに立つ位置、という対応（画面の図のとおり）
- **戻り**: シーン2の手前（カメラ側）の端（青の破線のゲート。机のそばから、カメラのほうへ少し歩く）に入ると、シーン1の廊下の奥（X 0.5m, Z 3.6m）へ、カメラのほうを向いて（180°）戻る
- ゲートは、床の上に置いた多角形（検出結果の表示で、青の破線）。切り替え先の位置・向きは `tools/calibrate.py` の `gates`（`enter_floor` と `enter_theta_deg`）で決める
- **2枚の写真の位置関係は、厳密には合わせていない**: それぞれの写真で、床・壁・カメラを別々に復元している。つなぎ目で、位置と向きを指定して入るだけ。シーン2 は、写真から廊下の幅を測れないので、**カメラの高さを 1.62m（シーン1 の 1.65m に近い値）と仮定**して、廊下の幅 0.84m を逆算している
- シーン2の床: 手前の広い部分（左の硝子戸の前〜大きな壁の手前）と、奥へのびる狭い廊下（幅約0.8m）。右の大きな壁の下・右下のテーブルは通れない（体の半径 0.2m で当たり判定）
