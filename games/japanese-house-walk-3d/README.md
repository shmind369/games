# japanese-house-walk-3d

設計図(2階の間取り)をもとに作った和室の家を、一人称視点で歩き回れるウォークスルー(Three.js製、スマホ縦画面向け)。
操作方法は school-walk-3d と同じ。

## 操作
- 画面左下をドラッグ: 移動(大きく倒すと走る)
- それ以外の場所をドラッグ: 見回す
- 右上の地図をタップ: 地図の拡大/縮小
- PC: WASD / 矢印キー + マウスドラッグ(Shiftで走る)

## 間取り
和室4.5畳・和室6.0帖・和室7.0畳・押入×2・廊下・階段・トイレ・北と南のバルコニー。
寸法は設計図の数値(mm)を使用。`main.js` 冒頭の `rooms` / `extWalls` / `intWalls` / `openings` で編集できる。
