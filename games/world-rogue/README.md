# WORLD ROGUE(第1弾: ワールド+移動+戦闘+レベルアップ)

戦闘画面への切り替えが存在しない、シームレスオープンフィールド型のターン制
ローグライクRPGの第1弾です。プレイヤーが1回行動すると世界が1ターン進行します。
素の2D Canvasで実装しています(Three.js等は未使用)。

**このリポジトリの他のゲームと同様、いきなりフル機能を作るのではなく段階的に
実装しています。** 今回の第1弾では「ワールドマップ+移動+マップ上戦闘+
レベルアップ」までを対象にしています(詳細は下記「スコープ外」を参照)。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/world-rogue
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 画面下部の**十字ボタンで東西南北に1マス移動**(1回の行動=1ターン)
- 移動先に敵がいると、そのまま**ぶつかって攻撃**(戦闘画面への切り替えなし)
- 「待機」「防御」ボタンでも1ターン消費。防御中は被ダメージが軽減される
- 右上の🗺ボタンでワールド全体の縮小マップを表示。ゲーム開始直後から
  ラスボス城の位置を確認できる(仕様書の設計方針①に対応)
- 敵を倒すと経験値を獲得し、たまるとレベルアップ(HP/MP/攻撃/防御が上昇)
- HPが0になるとゲームオーバー(最初からやり直せる)

## ワールド構成(仕様書 Ver.0.2 準拠)

- 100×100マス、外周はすべて海のシームレスマップ
- 最初の街(南)からスタート
- ラスボス城は北の孤島にあり、**開始直後から見えるが橋に鍵がかかっていて
  到達できない**(現時点では解錠する手段が未実装のため、この第1弾では
  常に鍵がかかったまま)
- 岩の迷宮(西)・ピラミッド(東)の入口は地図上に配置済みで、
  どちらからでも自由な順番で到達できる(一本道ではない設計)
- 草原・森・山・砂漠・沼地・川・道・橋などの地形

## 仕組みメモ

- 判定ロジックはDOM/Canvasから独立した純粋関数にしている
  - `isPassable` — 地形が通行可能かどうか
  - `resolveBump` — 移動先が「移動」「攻撃」「進めない」「鍵がかかっている」の
    どれに解決されるかを判定
  - `computeDamage` / `applyDamage` — ダメージ計算とHPクランプ
  - `xpForLevel` / `applyXp` — 経験値カーブとレベルアップ判定(複数レベル同時
    アップにも対応)
  - `computeCameraOrigin` — プレイヤーを追従しつつマップ端でクランプするカメラ
- ワールド生成は**シード固定の疑似乱数(mulberry32)**による、地形ごとの
  領域(ノイズを効かせた楕円・矩形・パス)を重ね合わせる方式。プレイのたびに
  地形が変わらない、作り込まれた1つの世界として扱っている
- 「ラスボス城が見えるが到達できない」という設計方針を、実際にBFS(幅優先探索)
  で「街からラスボス城への到達可能パスが存在しないこと」「街から両方の迷宮
  入口へは到達可能であること」をテストで検証している
- 敵の思考ルーティンはプレイヤーの状態を見ずに、隣接していれば攻撃、
  近ければ接近、それ以外はときどきランダムに徘徊するだけのシンプルなもの
