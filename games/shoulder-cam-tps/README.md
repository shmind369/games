# Shoulder Cam TPS（スマホ縦画面・肩越しカメラ プロトタイプ）

自作の**中華娘モデル**（`assets/china_rigged.glb`、既存のモデル・リグ・歩きモーション `walk.json` をそのまま使用。仮モデルへの置き換えはしていない）で、『バイオハザード リベレーションズ』風の**肩越しカメラ**の操作感・視点を、**スマホ縦画面**（iPhone Safari など）で確かめるための試作。敵AI・本格的な戦闘・ステージ生成は後回しで、**移動とカメラ操作を優先**している。

- 開く: `index.html`（3Dは `vendor/` の three.js を使う。ネット接続は不要）。モデルの読み込みに失敗したときは、画面に**原因（どのファイルか・エラー内容）**を出す

## 操作
| | |
|---|---|
| **左下** 仮想スティック | 移動。カメラの向きが基準（上 = カメラの前）。**少し倒す = 歩き / 大きく倒す（70%〜）= 走り**（スティックの輪が金色に光る）。離すと止まる。**構えていないときは、倒した向きへ即クイックターン**（下記）して歩き出す |
| **右側スワイプ**（画面の右60%で始めた指） | カメラ。**左右 = 回転、上下 = 上下の視点調整**（上へ = 上を向く / 下へ = 見下ろす）。移動中にスティックと同時に使える |
| **右下** 照準 | タップで切り替え / 0.35秒以上の長押しは「押している間だけ」。照準中は、カメラが自機に寄って肩越しになり（距離・FOV を縮める）、中央に照準が出て、自機はカメラの正面を向き、右腕を前へ構える。移動は遅くなる |
| **右下** 攻撃 | 試作用: 視線の先（照準中）／ 自機の正面へ弾の線を飛ばし、当たった位置に火花。反動でカメラが少し跳ねる |
| **右下** 回避 | 移動方向（なければ正面）へ、約0.4秒で3m のダッシュ（0.6秒のクールダウン） |
| **右上 ⚙** | カメラ調整パネル（下記） |
| PC | WASD / 矢印 = 移動、マウスドラッグ = カメラ、Space = 攻撃、Shift = 照準、E = 回避 |

- **カメラの自動追従**: 前へ歩いていて、0.9秒以上スワイプしていないときだけ、カメラがゆっくり自機の向きへ回り込む（旋回が急にならないよう、追従の速さは `follow`）。後ろ向きに歩くときは追従しない（急に180°回らない）
- **壁よけ**: 自機の頭からカメラへの線が壁・箱にぶつかるときは、まずカメラを**上へ持ち上げて見下ろす**ことでよけ、それでもだめなら手前で止める（めり込まない。画面上部の表示に「壁よけ」と出る）。近づくのは一瞬、離れるのはゆっくり

## カメラの初期値（指示書の目安に合わせた）
| 項目 | 初期値 | 指示書の目安 |
|---|---|---|
| 距離 `dist` | 2.4 m | 2.0〜2.5 m |
| 高さ（`elev` 9° → カメラの高さ） | 約 1.8 m | 1.2〜1.8 m |
| 下向き角（`elev` + `pitchBias` 7°） | 約 16° | 10〜20° |
| 右肩オフセット `shoulder` | 0.30 m | 右肩後方（ややオフセット） |
| 画角 `fov` | 62°（縦画面は横の画角が狭いので、広めにしている） | — |

照準中: 距離 1.8m / 肩 0.34m / FOV 52°。

### ⚙ 調整パネル（実機でその場で確認して、値を決める）
距離・仰角（高さ）・視線の下向き上乗せ・右肩オフセット・FOV・スワイプ感度（横・縦）・追従の速さ・照準時の距離／肩／FOV をスライダーで変えられる。値はブラウザに保存される。「値をコピー」で現在の値（JSON）を取り出せるので、決まった値を `main.js` の `DEFAULTS` に反映する。

## テスト環境
薄暗い倉庫（32m四方）: 棚の列・柱・木箱の山・ドラム缶・暖色のランプ。東側に**幅1.4mの狭い通路**（南の入口 → 北へ → 東の部屋へ折れる）。床には2m角のタイルの目地と黄色い線（足元と進行方向が分かる目印）、自機の足元に丸い影。

## 今回の検証項目（確認のしかた）
1. **縦画面での大きさ**: 全身が見え、画面の高さの約6割。自機は画面の左寄り（右肩後方のカメラ）に映る
2. **足元と進行方向**: 床のタイル・線で進行方向がわかる。足元は、左下のスティックと少し重なる位置（スティックは半透明）
3. **片手・両手の操作**: スティック（左親指）とスワイプ（右親指）を同時に使える。ボタンは右下。照準のタップ切り替えで、照準したまま右親指をスワイプに使える
4. **旋回時のカメラ**: スワイプは小さなスムージング（約0.05秒の遅れ）で、急に回転しない。自動追従は前進時だけ・ゆっくり
5. **狭い通路**: 通路内でもカメラが壁にめり込まず、自機と前方が見える（通路の幅より距離が長くても、まっすぐな通路ならカメラは通路の中に収まる）。壁を背にしたときは、上から見下ろしてよける

`index.html`（画面・UI）/ `main.js`（ゲーム全体）/ `assets/china_rigged.glb` / `assets/walk.json` / `vendor/`（three.js と GLTFLoader）

## クイックターン（構えていないとき、スティックを倒した向きへ即ターン）
- **構えていない状態**でスティックを倒すと、**倒した向きへ自機が一瞬で（約0.1秒以内に）向きを変えて**歩き出す。**前・後ろ・左・右・斜めのどの向きでも**（後ろへ倒せば 180°、斜め後ろなら 135° など）。後ろ向きには歩かず、向き直ってから進む
- 倒しはじめの `QUICK_TURN_MS`（0.22秒）は特に速く（`QUICK_TURN_RATE`）、そのあと歩いている間に向きを変えるときも速い（`TURN_RATE`）。ターンのあいだは、**上半身と頭が向く先へ先に回り**、体があとから追いつく
- **構え（照準）中はクイックターンしない**: 自機はカメラの正面を向いたまま、スティックでカメラ基準の方向へ（向きを変えずに）動く
- 実測（スティックを各向きに倒す）: 右 90° / 左 90° / 後ろ 180° / 前 0° / 斜め後ろ右 135° を、すぐに向く。構え中は 0°
