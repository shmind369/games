# 3Dバッティングセンター

Three.js製の3Dバッティングセンター風ミニゲーム。ビルド不要でブラウザで直接動きます。
スマートフォンの縦持ちでのプレイを前提としたタッチ操作専用UIです。

投手・打撃・全10球のバッティングだけを楽しむ、いわゆる「バッティングセンター」形式です
(守備・走塁・イニングはありません)。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。
Three.js (`vendor/three.module.min.js`, v0.160.0) はリポジトリに同梱しているので、
外部CDNへのアクセスなしで動作します。

```bash
cd games/batting-center-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 投げられた球が来たタイミングで**画面のどこでもタップ**してスイング
- ジャストミートに近いほど良い結果(ホームラン>ヒット>ファウル>空振り/見逃し)
- 全10球で終了。スコア・ヒット数・ホームラン数の結果が表示される

## 仕組みメモ

- 表示される球速(km/h)は雰囲気用の数値で、実際の到達時間はスマホでの反応が
  現実的になるよう倍率(`GAME_TIME_SCALE`)でゆっくりに調整している
- ヒット判定は「理想の到達タイミングとタップした瞬間との誤差」のみで決まる
  (左右への打ち分けはない、タイミングゲームとしてシンプルに割り切っている)
- 判定の許容幅は到達時間に対する割合で決めているので、速い球ほど許容幅が
  狭くなり自然に難易度が上がる
- 判定ロジック(`evaluateSwing`)は描画・DOM操作から完全に分離した純粋関数にしており、
  合成的なタップタイミングを与えて単体テストしやすい構造にしている
