# Whip Physics 3D

「鞭(ムチ)」の挙動を、アニメーションではなく**物理演算のみ**で再現したThree.js製プロトタイプです。
根元を引っ張って離すと、鞭が根元から先端へ波のように伝わりながら加速し、
先端が最も速く動く「鞭打ち効果(Whip Effect)」が発生します。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/whip-physics-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- **鞭をドラッグして引っ張り**、指を離すと弾ける
- 引っ張る量が大きい(=速い)ほど、鞭に蓄積されるエネルギーが大きくなる
- 右上の⚙アイコンから、Stiffness・Damping・質量比・節の数・空気抵抗を
  リアルタイムに調整できる

## 物理モデル

鞭は20〜40個の質点(パーティクル)を距離拘束(Distance Constraint)で連結した
**Position Based Dynamics(PBD)方式のVerletチェーン**として実装しています。

- 各ステップで重力・空気抵抗を積分し、その後、距離拘束を複数回反復して解く
  (Thomas Jakobsenの手法、Müllerらの"Position Based Dynamics"と同じ枠組み)
- 根元のみプレイヤーの操作で直接位置を設定する(キネマティック)。それ以外の
  質点は完全に物理演算に従う
- 指を離した瞬間は「拘束を解除する」のではなく、**根元をキネマティック制御
  から外すだけ**にしている。Verlet積分は位置の履歴(前フレーム位置との差分)
  から速度を導出する方式のため、ドラッグ中に蓄積された根元の速度はそのまま
  保持され、拘束を通じて鞭全体へ自然に伝播していく

### 鞭打ち効果(Whip Effect)の正体 = 質量のテーパリング

このシミュレーションで「鞭」と「ロープ」を分けている**唯一かつ最も重要な要素**は、
質点の質量を根元から先端に向けて指数的に軽くしていること(`質量 = 質量比^(index/節の数)`)です。

同じ運動量・エネルギーが軽い質点に伝わるほど、運動量保存則により速度は増加します。
実際に本リポジトリのテストで、同じ「引っ張って離す」操作を

- 質量が均一(質量比=1.0、つまりロープ)の場合 → 先端速度は根元より**遅く**なる
- 質量をテーパリングした鞭(質量比=0.06)の場合 → 先端速度は根元の**約1.7倍**に達する

という結果を確認しています。**波形をスクリプトで生成する処理は一切なく**、
上記の質量分布・距離拘束・Verlet積分だけでこの現象が創発します。

## 調整項目

| パラメータ | 説明 |
| --- | --- |
| Stiffness | 距離拘束の1反復あたりの補正の強さ(0〜1)。低いほど伸び縮みしやすい柔らかい鞭になる |
| Damping | 毎ステップの速度の減衰率。内部エネルギー損失に相当 |
| 質量比(先端/根元) | 先端の質量が根元の何倍か。小さいほど鞭打ち効果が鋭くなる。1.0にするとロープのような挙動になる |
| 節の数 | 質点の数(20〜40)。変更するとその場でチェーンを再構築する |
| 空気抵抗 | 速度の2乗に比例する抗力係数 |

## 仕組みメモ

- 物理演算は**固定タイムステップ(1/120秒)のサブステップ方式**で実行しており、
  可変フレームレートでもPBD拘束ソルバーが不安定にならないようにしている
- 距離拘束の解決ロジック(`solveDistanceConstraint`)と質量計算(`taperedMass`)は
  DOM/Three.jsから独立した純粋関数にしており、座標だけを渡して単体テストできる
- 開発中、根元の速度をVerletの位置履歴から正しく引き継がせる実装(「拘束を外す」
  だけで「速度をリセットしない」)が、鞭打ち効果の再現に不可欠であることを
  確認している。素朴に根元の前フレーム位置をリセットしてしまうと、その瞬間に
  速度がゼロになり、鞭がただ垂れ下がるだけになってしまう
- 引っ張れる距離には上限を設けている(現実の腕の可動域に相当)。上限がないと、
  画面を大きくスワイプしただけで非現実的に鞭が加速してしまうため
- カメラは毎フレーム、鞭の全質点を包む球(バウンディングスフィア)を計算し、
  その球が視錐台に収まる距離まで**自動でズームアウト/インする**オートフレーミング
  方式にしている。ズームアウトは即座に(1フレームでも画面外に出さない)、
  ズームインは滑らかに行う非対称な追従にすることで、強いフリック直後でも
  鞭が画面外へ飛び出さないようにしている
