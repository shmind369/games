# 路上デュエル・プロトタイプ

ファミコン初期にあった「上段・下段のパンチとガードだけで、相手を画面端まで
押し出せば勝ち」という1対1の路上格闘ゲームの操作感を検証するための
プロトタイプです。HPバーはなく、**押し合い(タグ・オブ・ウォー)一本勝負**です。
Three.js等の外部ライブラリは使わず、素の2D Canvasで実装しています。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/street-duel-prototype
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 画面下部の **「上段」「下段」ボタン**を使う
  - **タップ**(素早く指を離す)→ その段にパンチを繰り出す
  - **ホールド**(押さえたまま)→ その段をガードし続ける
- 相手の攻撃と同じ段をガードしていれば防御成功。段が合っていない・ガードしていなければ被弾する
- パンチが命中すると、相手を1歩ぶん自分側の画面端(マンホール)へ押し込む
- 完全に端まで押し込めば即KOで勝敗が決まる。60秒のタイムアップ時は、
  押し合いがどちらに傾いているかで勝敗が決まる(五分五分ならDRAW)
- パンチを出した後は短いスキ(反撃を受けやすい隙)が発生し、連打はできない
- ときどき上から物(植木鉢のようなもの)が降ってくる。**上段をガードしていないと直撃**し、
  直撃した側が1歩押し込まれる

## 仕組みメモ

- 押し合いの位置は `-EDGE_LIMIT`〜`+EDGE_LIMIT` の一次元スカラー値(`battlePosition`)
  1つだけで表現しており、両端に到達した瞬間に即KOと判定できるシンプルな構造にしている
- 判定ロジックはDOM/Canvasから独立した純粋関数にしている
  - `resolvePunch` — 攻撃の段とガード状態からヒット/ブロックを判定
  - `resolveHazard` — 落下物への対応(上段ガードのみ回避可能)を判定
  - `applyPush` / `checkRoundEnd` — 押し込みと決着判定
  - `resolveTimeout` — タイムアップ時の判定
- 「タップ=パンチ、ホールド=ガード」は同じボタンで両方を賄っており、
  押してから一定時間(`HOLD_THRESHOLD_MS`)経過するまで指を離さなければガードに昇格する
  (毎フレーム判定しているため、ガード中に相手の攻撃へリアルタイムに間に合う)
- CPUはプレイヤーの状態を一切参照せず、独立したランダムタイマーで行動を選ぶ
  (プレイヤーの入力を読んで反応するような不公平なAIにはしていない)
