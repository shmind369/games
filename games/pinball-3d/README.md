# Pinball 3D

Three.js製のシンプルな3Dピンボール。ビルド不要でブラウザで直接動きます。
スマートフォンの縦持ちでのプレイを前提としたタッチ操作専用UIです。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください（`file://` だと
ES Modules / importmap がブロックされるブラウザがあるため、サーバー経由を推奨）。
Three.js (`vendor/three.module.min.js`, v0.160.0) はリポジトリに同梱しているので、
外部CDNへのアクセスなしで動作します。

```bash
cd games/pinball-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- **フリッパー**: 画面左半分/右半分をタップで左右のフリッパーを操作
- **発射**: 右上の「押して発射」ボタンを長押しするほど強く発射(最大約0.9秒)
- **得点**: 赤いバンパーに当てると+10点
- **ボール喪失**: フリッパーで受け止められず一番下まで落ちるとボール喪失。3球でゲームオーバー
- **画面向き**: 縦持ち専用。横向きにすると案内が表示されプレイが止まる

## 仕組みメモ

- 物理は全てXZ平面上の2D処理(Yは見た目の高さのみ)。重力は+Z方向(プレイヤー側)へ一定加速
- 壁とフリッパーは同じ「線分(カプセル)とボールの衝突」関数で処理している
  (`resolveSegmentCollision`)。フリッパーが `active` かつ動作中に接触すると、
  通常の反射ではなく強めのキック速度をボールに与える
- バンパーは円と円の衝突。当たると得点加算・ボールを弾き飛ばし・簡単な拡大アニメーションを再生
- 発射レーンは右端の仕切り壁(`LANE_X`)で区切られており、壁が上端手前で途切れているため、
  発射したボールは上の壁に当たって跳ね返り、そのまま本編フィールドへ流れ込む
