# WORLD HISTORICAL ATLAS

ユーザーから提供された、ある「世界歴史地図(The World Historical Atlas)」という
既存アプリの`index.html`/`style.css`(参照されているJSファイル本体は
含まれていなかった)を仕様の参考に、パン・ズームできる世界地図と
年表バーで歴史を辿るアプリとして一から再実装したプロトタイプです。
地図タイルや人物の肖像画などの素材データは手元になかったため、大陸は
簡略化した図形で表現し、歴史データは同リポジトリの`world-history-viewer`
が持つデータセットをそのまま共有しています。3D空間・Three.js等は
使わない素のCanvas/DOM/CSS/JS製の単一ページアプリです。

`world-history-viewer`(年号を打ち込んで一覧するテキスト中心のビューア)
とはUIの切り口が異なるだけで、同じ歴史データを別の見せ方で探索できる
姉妹アプリという位置づけです。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/world-historical-atlas
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 地図を指でドラッグして**パン**、右側の縦スライダーをドラッグして**ズーム**
  (上ほど拡大)できる
- 色のついた地域(日本・中国・ヨーロッパ・中東)を**タップ**すると、
  現在選択中の年の時代区分と、その年に生きていた人物一覧がシートで
  表示される。地域の色は選択中の年の時代区分(古代/中世/近世/近代/現代)に
  応じて変化する
- 画面右上の年号表示を**タップ**すると直接年数を入力できる(西暦・
  マイナス値で紀元前を指定)。下部の**◀/▶**ボタンで1年ずつ移動、
  長押しで加速する。年表バー(下部の横棒)を直接ドラッグすると
  大まかに好きな年へジャンプできる
- 左上の**日本語/EN/中文**ボタンでUIの文言(ボタン・見出し・年号の
  書式など)を切り替えられる

## 実装メモ

地図のレイアウト・カメラ変換・年表/ズームスライダーの座標変換・UI文言の
多言語辞書は`worldmap.js`にDOM/Canvas非依存の純粋関数としてまとめている
(Node上で直接ユニットテスト可能)。年齢計算・時代区分の特定・人物の
抽出など歴史データそのものへの問い合わせロジックは、既存の
`world-history-viewer/history.js`と`data.json`をそのまま複製して
再利用している(データを二重管理する代わりに、まず同じデータの
上に異なる見せ方のUIを作るという方針)。

- **地図の座標系**: 正規化された0〜1のマップ空間に、日本・中国・
  ヨーロッパ・中東の4地域を簡略化した楕円として手動で配置している
  (`REGION_SHAPES`)。実際の海岸線データは持っていないため、緯度経度的に
  おおよそ正しい位置関係の図形で代用しており、正確な地図として見せる
  ことは意図していない。パン・ズームは「マップ空間の点をスクリーン座標へ
  変換する」`mapToScreen`と、その逆変換`screenToMap`という一組の純粋関数で
  表現し、タップ位置の当たり判定(`hitTestRegion`)は screenToMap で
  マップ空間に戻した点を各地域の楕円と比較するだけで実現している
- **地域の色 = 時代区分**: 元の参照アプリでは、年を動かすと領土(勢力圏)の
  色が変わる、という演出だったが、勢力圏の詳細な国境データは用意できない
  ため、代わりに各地域の「現在の時代区分の大分類(古代/中世/近世/近代/現代)」
  で色分けする、という形に置き換えた。地域ごとに`eras`データが定義されて
  いる範囲より前の年(例: 紀元前2500年のヨーロッパ)は、まだ記録されて
  いないことを示すニュートラルな色になる
- **ズームスライダーの向き**: 参照アプリは横長スライダーだったが、
  スマホ縦画面では横幅が貴重なため、同じ「トラック上の位置→ズーム値」
  という計算(`zoomFromSliderX`/`sliderXFromZoom`)を縦向きのスライダーに
  流用する形に変更した(呼び出し側で縦距離を横距離として渡しているだけで、
  関数自体に上下左右の区別はない)
- **年表バーの3段階の精度**: -4000年から2019年という約6000年の範囲を
  スマホ1画面の横幅に収めると、ドラッグ操作では1ピクセルあたり十数年
  ズレてしまう。これを補うため、(1) バーのドラッグ = 大まかな移動、
  (2) ◀/▶ボタンの1タップ = 1年ずつの移動(長押しで加速)、
  (3) 年号表示のタップ = 直接入力による厳密な指定、という3段階の
  操作を用意し、精度が必要な操作は数値入力に任せる設計にした
- **多言語対応の範囲**: 言語切り替えボタン(日本語/EN/中文)はUIの
  文言(ボタン・見出し・年号の書式)のみを切り替える。時代区分名や
  人物名・説明文といったデータ本体は日本語のみで、言語を切り替えても
  翻訳されない。専門的な歴史用語を英語・中国語へ正確に翻訳するには
  相応の検証が必要なため、今回のプロトタイプではUIの言語切り替え機構を
  実装することを優先し、データの翻訳は範囲外とした

## テスト

- `worldmap.js`の純粋関数をNode上でユニットテスト(年のクランプ・
  地域の当たり判定・時代区分による色分け・ズームクランプ・パンの
  クランプ・カメラ座標変換の往復一致・ズームスライダー/年表バーの
  座標変換の往復一致・多言語文言の存在と未対応言語への
  フォールバック・年号の書式化)。既存の`history.js`/`data.json`との
  組み合わせ(1582年の日本の時代区分・在命人物・年齢計算)も
  合わせて検証している
- Playwrightで実際のポインタ操作を再現し、地図上の地域タップでの
  情報シート表示(人物一覧を含む)・背景タップでのシート閉じ・
  地図のドラッグによるパン・ズームスライダーのドラッグによる
  拡大縮小・年表バーのドラッグによる大まかな年移動・矢印ボタンの
  単発タップ(1年移動)と長押し(加速)・年号タップからの直接数値
  入力・3言語の切り替えを検証
  - 検証中、遠く離れた年(紀元前2500年)ではヨーロッパ・中国のように
    時代区分データがまだ存在しない地域があることを実際に確認した。
    これは実装上のバグではなく、データの範囲による正しい挙動である
- 紀元前2500年(古代)・1980年(現代)それぞれのスクリーンショットを撮り、
  同じ地域の色が時代区分に応じて実際に変化することを目視で確認
- ページエラー無しの最終スモークテストを実施
- `window.__debug`フックは最終コミット前に削除済み(`grep -n "__debug"`
  で該当なしを確認)

## スコープ外(意図的に未実装・今後の調整用)

- 正確な海岸線・国境データを用いた本格的な地図表示(現状は簡略化した
  図形による位置関係の再現のみ)
- 地域・データ本体(人物名・時代区分名など)の英語・中国語への翻訳
- 日本・中国・ヨーロッパ・中東以外の地域(アフリカ・南北アメリカ・
  オセアニアなど)のデータ追加(現状は背景の装飾図形のみでタップ不可)
- 人物の肖像画・詳細な生涯タイムライン画面(world-history-viewerには
  既にある機能だが、このアプリでは地図・年表の操作感の検証を優先した)
- URL共有・ブックマーク機能
