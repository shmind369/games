# COUNTER PUNCH 3D

一人称視点でリングに立ち、相手ボクサーが繰り出すパンチを見切って左右スワイプで
躱し、隙ができたらタップで反撃する対戦アクションです。往年の見切り＆カウンター型
ボクシングゲームの操作感にインスパイアされていますが、タイトル・キャラクター等は
完全オリジナルです。Three.js製(素のプリミティブ形状でボクサーを構築)。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/counter-punch-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- 相手のグローブが光って構えたら、パンチの**逆側へ左右スワイプ**して躱す
  (画面中央の案内表示が躱すべき方向を教えてくれる)
- 躱しに成功すると相手の隙が生まれるので、その間に**画面をタップ**して
  カウンターパンチを叩き込む
- 躱しそこねる(方向を間違える/反応が遅れる)とダメージを受ける
- 相手のHPを0にすればTKO勝利、自分のHPが0になるとKO負け

## 仕組みメモ

- 判定ロジックはThree.js描画から独立した純粋関数にしている
  - `classifySwipe(dx, dy, dt)` — ポインター操作の移動量・時間から
    「左スワイプ/右スワイプ/タップ/どちらでもない」を判定
  - `evaluateDodge` — 要求される躱し方向と実際のジェスチャーが一致するか判定
  - `computeTelegraphMs` — 相手の残りHP割合が低いほど予備動作(見切れる猶予)が
    短くなる難易度カーブ。「HPが減るほど相手が捨て身で速くなる」演出を兼ねる
  - `pickNextSide` — 同じ側への攻撃が3連続にならないよう調整した攻撃側の選択
  - `applyDamage` — HPのダメージ計算とクランプ
- 試合はフェーズ制のステートマシンで進行する:
  `waiting`(小休止) → `telegraph`(予備動作・入力受付) → 成功時は
  `vulnerable`(反撃受付) → `counterRecover`、失敗時は `hitRecover` →
  `waiting` に戻ってループ。相手または自分のHPが0になると `win`/`gameover`
- 一人称視点のため自キャラの姿は描画せず、躱し成功時のカメラの横ずれ、
  カウンター時のカメラの前進(ラッシュ)、被弾時の画面フラッシュ+カメラシェイクで
  プレイヤー側のアクションを表現している
