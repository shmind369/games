# Maze Runner 3D

Three.js製のシンプルな3Dアクション/迷路ゲーム。ビルド不要でブラウザで直接動きます。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください（`file://` だと
ES Modules / importmap がブロックされるブラウザがあるため、サーバー経由を推奨）。
Three.js (`vendor/three.module.min.js`, v0.160.0) はリポジトリに同梱しているので、
外部CDNへのアクセスなしで動作します。

```bash
cd games/maze-runner-3d
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- **移動**: WASD または矢印キー
- **目的**: 迷路内のコインをすべて集めるとクリア
- **敵**: 赤い敵に触れるとライフが減ってスタート地点に戻される。ライフが0でゲームオーバー

## 仕組みメモ

- 迷路は再帰的バックトラッカー法で毎回ランダム生成 (`generateMaze`)
- 壁は `InstancedMesh` でまとめて描画
- プレイヤーと壁の当たり判定は円と矩形の押し出し解決(circle vs AABB)
- 敵は隣接する通路セルをランダムに選んで移動するシンプルなランダムウォーク
- カメラはプレイヤーの向きに追従する三人称チェイスカメラ
