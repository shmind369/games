# 将棋

CPU対戦の将棋。ビルド不要でブラウザで直接動きます(Three.js等の外部ライブラリ不使用)。
スマートフォンの縦持ちでのプレイを前提としたタッチ操作専用UIです。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/shogi
python3 -m http.server 8080
# http://localhost:8080 を開く
```

- あなたは先手(盤面下側)。CPUが後手(盤面上側、駒は180度回転して表示)
- 自分の駒をタップ→緑丸が付いた移動先をタップで移動
- 持ち駒をタップ→打てるマスをタップで駒を打つ
- 敵陣(相手側3段)に入る/出る/内で動く手は成りを選択可能。歩・香が最終段、桂が最終2段に
  進む手は自動で成る(そうしないと二度と動けなくなるため)
- 二歩(同じ筋に自分の不成の歩を2枚打てない)や、行き場のないマスへの打ち歩・打ち桂は禁止
- 指し手のたびに「先手 ５六歩」のように棋譜を読み上げる(Web Speech API)。
  右上のスピーカーアイコンでON/OFF切り替え可能。先手の読み上げが終わってから
  少し間を置いて後手を読み上げるので重ならない
- 読み上げは駒の表示(漢字)と別に、正しい読み方(ひらがな)を音声合成に渡している
  (歩→ふ、香→きょう、桂→けい、銀→ぎん、金→きん、角→かく、飛→ひ、
  王→おう、玉→ぎょく、と→と、成香→なりきょう、成桂→なりけい、
  成銀→なりぎん、馬→うま、龍→りゅう)

## ルール上の割り切り

本将棋の王手・詰み・千日手・打ち歩詰めの判定は実装していません。**玉を取ったら
即座にその場でゲーム終了**というシンプルなルールにしています。それ以外の駒の動き・
成り・持ち駒・二歩などのルールは通常の将棋と同じです。

## CPU思考ルーチン

- アルファベータ枝刈り付きのnegamax探索。持ち駒の数によって合法手数(=分岐数)が
  数十〜数百と大きく変動するため、固定深さではなく**反復深化+時間制限(約900ms)**
  で探索する。単純な局面ではより深く、複雑な局面では浅い深さで確実に着手を返す
- 評価値は駒の価値の合計(歩1、香3、桂4、銀5、金6、角8、飛10、成駒はおおむね金〜龍相当、
  玉は圧倒的に高い値)+持ち駒のボーナスに加えて、簡単な局面評価
  (歩の前進度、駒の中央志向、玉の周りの守り駒の数)を加算
- 枝刈り効率を上げるため、駒を取る手・成る手を優先して読む順序にしている
- 成れる場面では基本的に必ず成る(戦術的に成らない方が良い場面もあるが、簡易化のため)
- 同程度の評価の手が複数あるときのために評価値へわずかなランダム性を加えている
