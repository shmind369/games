# HIP DROP! ver.0.1

スマートフォン(縦持ち・片手操作)向けの三人称3Dジャンプアクション試作版。Three.js のみ使用(物理・当たり判定は自前)。
空中から真下へ急降下する **ヒップアタック** で敵を倒し、旗のゴールを目指します。

## 操作

タイトル画面で操作タイプを切り替えられます(選択は端末に保存。URL に `?pad=classic` / `?pad=center` でも指定可)。

**センターパッド(既定)** — 画面下中央に固定の移動パッド
- パッドをドラッグ → 360度移動(外側の輪を押せばジャンプせずにそのまま移動できる)
- パッドの真ん中(点線の円)をタップ → ジャンプ(タップでも常にフルジャンプ)
- ジャンプ中にパッドを下へすばやくはらう → ヒップアタック(真ん中タップ → そのまま下へはらう、の一動作で出せる)

**左パッド+ボタン(従来)**

| | スマホ | PC |
| --- | --- | --- |
| 移動(360度) | 画面左下をドラッグ(押した位置にスティックが出る) | WASD / 矢印 |
| ジャンプ | 右下の JUMP をタップ(長押しで高く、すぐ離すと小ジャンプ) | Space |
| ヒップアタック | ジャンプ中に下スワイプ(JUMP を押したまま下へはらうのが最速) | Shift / K |
| カメラ回転 | パッド以外の場所を横ドラッグ | マウス横ドラッグ |

どちらの操作タイプでも、パッド以外の場所での下スワイプでヒップアタックが出せます。

- ヒップアタック: 空中で一瞬止まって前転 → 水平移動を止めて真下へ急降下 → 着地で衝撃波
- 敵に直撃すると撃破して高く跳ね返る。着地の衝撃波でも近くの敵を倒せる
- 着地硬直中にジャンプすると **大ジャンプ**
- 敵はトゲ付きなので普通に踏んでも倒せない(跳ね返るだけ)。横から触れるとダメージ
- ハート3つ。落下・ダメージで減り、0でゲームオーバー

## 操作感のための工夫

- 固定時間刻み 1/120 秒 + 描画補間(フレームレートに依存しない)
- コヨーテタイム(足場から落ちた直後もジャンプ可)、ジャンプ先行入力、可変ジャンプ、落下時の重力を強めにしてキビキビ
- 下スワイプは「直近0.35秒の動き」で判定するので、JUMP を押しっぱなしにしてから頂点で下へはらっても発動
- 空中では足元に丸影と落下地点リングを表示(どこに落ちるか分かる)
- 命中時のヒットストップ・画面揺れ・衝撃波・土煙・合成効果音
- カメラは移動中に背後へ回り込み、カメラに向かって走るときは回り込まない(ぐるぐる回り防止)。壁に遮られると手前に寄る

## ファイル構成(機能ごとに独立)

| ファイル | 役割 |
| --- | --- |
| `js/config.js` | 速度・ジャンプ力・重力・ヒップアタック・カメラなど調整値をすべて集約 |
| `js/input.js` | 仮想スティック・ジャンプボタン・スワイプ・キーボード |
| `js/player.js` | プレイヤーの状態機械(通常/溜め/急降下/着地)と見た目のアニメーション |
| `js/collision.js` | 円柱 vs 箱(AABB)の衝突解決 |
| `js/camera.js` | 三人称追従カメラ |
| `js/enemies.js` | 敵の徘徊・撃破演出 |
| `js/stage.js` | テストステージ(足場・壁・敵配置・ゴール) |
| `js/effects.js` | 衝撃波・パーティクル・揺れ・効果音 |
| `js/main.js` | ゲーム進行・戦闘判定・UI |
