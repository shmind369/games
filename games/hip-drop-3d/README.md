# HIP DROP! ver.0.1

スマートフォン(縦持ち・片手操作)向けの三人称3Dジャンプアクション試作版。Three.js のみ使用(物理・当たり判定は自前)。
空中から真下へ急降下する **ヒップアタック** で敵を倒し、旗のゴールを目指します。

## 操作

タイトル画面で操作タイプを切り替えられます(選択は端末に保存。URL に `?pad=gesture` / `?pad=center` / `?pad=classic` でも指定可)。

**ジェスチャー(既定)** — 指1本、画面のどこでも
- 指を 15px 以上スライド → 移動(触れた位置にスティックが現れ、指の方向と距離で移動)
- 動かさずに短く(0.28秒以内)タップ → ジャンプ。判定は **指を離したとき** に行い、タッチ開始時には跳ばない
- 一度でも 15px を超えて動かした指は、元の位置に戻して離してもジャンプしない
- 走りながらすばやく上へはらう → **走り幅跳び**(下記)
- 空中ですばやく下へスワイプ → ヒップアタック(地上では発動しない。走り幅跳び中も可)
- 1本目の指は pointerId で管理し、2本目以降の指はカメラ回転専用(1本目と混同しない)
- iOS Safari のダブルタップ拡大・長押し選択・ピンチ拡大を抑止。入力処理は Pointer Events のみで、touch 系イベントは既定動作の抑止だけに使う(二重発火しない)
- 調整値: `js/config.js` の `INPUT.moveThreshold`(15px)・`INPUT.tapMaxTime`(0.28秒)・`INPUT.padFlickDy`(はらいの距離)

**センターパッド(既定)** — 画面下中央に固定の移動パッド
- パッドをドラッグ → 360度移動(外側の輪を押せばジャンプせずにそのまま移動できる)
- パッドの真ん中(点線の円)をタップ → ジャンプ(タップでも常にフルジャンプ)
- ジャンプ中にパッドを下へすばやくはらう → ヒップアタック(真ん中タップ → そのまま下へはらう、の一動作で出せる)

**左パッド+ボタン(従来)**

| | スマホ | PC |
| --- | --- | --- |
| 移動(360度) | 画面左下をドラッグ(押した位置にスティックが出る) | WASD / 矢印 |
| ジャンプ | 右下の JUMP をタップ(長押しで高く、すぐ離すと小ジャンプ) | Space |
| 走り幅跳び | 走りながらスティックを上へすばやくはらう | L / E |
| ヒップアタック | ジャンプ中に下スワイプ(JUMP を押したまま下へはらうのが最速) | Shift / K |
| カメラ回転 | パッド以外の場所を横ドラッグ | マウス横ドラッグ |

どちらの操作タイプでも、パッド以外の場所での下スワイプでヒップアタックが出せます。

- ヒップアタック: 空中で一瞬止まって前転 → 水平移動を止めて真下へ急降下 → 着地で衝撃波
- 敵に直撃すると撃破して高く跳ね返る。着地の衝撃波でも近くの敵を倒せる
- 着地硬直中にジャンプすると **大ジャンプ**
- 敵はトゲ付きなので普通に踏んでも倒せない(跳ね返るだけ)。横から触れるとダメージ
- ハート3つ。落下・ダメージで減り、0でゲームオーバー

## ジャンプの種類(ver.0.2)

| | 入力 | 高さ | 水平方向 | 飛距離の目安(平地) |
| --- | --- | --- | --- | --- |
| 静止ジャンプ | 止まってタップ | 2.5m | 0 から(空中で入力方向へ加速可) | その場 |
| 走行ジャンプ | 走りながら Space / ボタン | 2.5m | 走行速度をそのまま引き継ぐ | 約5.3m |
| 走り幅跳び | 走りながら上フリック / L | 1.9m(重力×0.65でふわっと) | 直前の走行速度 × 1.45 | 約7.9m |

- ジャンプしても水平速度はリセットしない。垂直方向にだけ専用の初速を与える
- 空中では進行方向を最大 3.2 rad/s で入力方向へ回す(地上より緩やか)。速さは保ち、急減速・急停止しない
  (入力を離すとゆるやかに減速、逆方向に入力するとブレーキ)
- 走り幅跳びの勢いは空中でもほとんど落ちず、着地後もそのまま走り続けられる(超過分だけゆっくり落ちる)
- 判定にかかった時間で減速しても、直近 0.18 秒の最高速度で踏み切るので飛距離が縮まない
- 上フリックで動いた指の分はスティック入力から差し引き、フリック前の進路と速さを保つ
- 上フリックの判定: 上方向 34px 以上・450px/s 以上・真上から 35° 以内・0.14 秒以内。移動開始から 0.15 秒は判定しない
  (ゆっくり上へドラッグ=前進、歩き出しの勢い、斜めのスライドとは区別)。走行速度が最高速の 45% 未満のときは受け付けない
- 踏み切りのアニメーションは物理と同じステップで切り替わる: 走行ジャンプは片脚を前に出す踏み切り、走り幅跳びは脚を前後に大きく開き前傾 → 下降で両脚を前へ
- 調整値は `js/config.js`: `jumpHeight` / `longJumpHeight` / `longJumpSpeedMul`・`longJumpMinSpeed`・`longJumpMaxSpeed`(水平初速) /
  `airAccel`・`airDecel`・`airBrake`・`airOverspeedDecel`(空中の加減速) / `airTurnRate`(空中の方向転換) / `INPUT.upFlick*`(上フリック)

## 操作感のための工夫

- 固定時間刻み 1/120 秒 + 描画補間(フレームレートに依存しない)
- コヨーテタイム(足場から落ちた直後もジャンプ可)、ジャンプ先行入力、可変ジャンプ、落下時の重力を強めにしてキビキビ
- 下スワイプは「直近0.35秒の動き」で判定するので、JUMP を押しっぱなしにしてから頂点で下へはらっても発動
- 空中では足元に丸影と落下地点リングを表示(どこに落ちるか分かる)
- 命中時のヒットストップ・画面揺れ・衝撃波・土煙・合成効果音
- カメラは移動中に背後へ回り込み、カメラに向かって走るときは回り込まない(ぐるぐる回り防止)。壁に遮られると手前に寄る

## ファイル構成(機能ごとに独立)

| ファイル | 役割 |
| --- | --- |
| `js/config.js` | 速度・ジャンプ力・重力・ヒップアタック・カメラなど調整値をすべて集約 |
| `js/input.js` | 仮想スティック・ジャンプボタン・スワイプ・キーボード |
| `js/player.js` | プレイヤーの状態機械(通常/溜め/急降下/着地)と見た目のアニメーション |
| `js/collision.js` | 円柱 vs 箱(AABB)の衝突解決 |
| `js/camera.js` | 三人称追従カメラ |
| `js/enemies.js` | 敵の徘徊・撃破演出 |
| `js/stage.js` | テストステージ(足場・壁・敵配置・ゴール) |
| `js/effects.js` | 衝撃波・パーティクル・揺れ・効果音 |
| `js/main.js` | ゲーム進行・戦闘判定・UI |
