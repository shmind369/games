# コンビニレジ打ちゲーム

コンビニのレジ打ち作業を、スマホ縦持ち・片手操作向けに再現したシミュレーションゲームです。
外部ライブラリは使わず、素のHTML/CSS/JSで実装しています。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
cd games/konbini-cashier
python3 -m http.server 8080
# http://localhost:8080 を開く
```

1. お客さんが持ってきた商品(バーコード付きカード)を**タップしてスキャン**する
2. 全部スキャンすると画面上部に**合計金額**が表示される
3. 表示された金額を**テンキーで正確に打ち込んで「会計」**を押すと会計完了、お客さんが退店
4. 金額を打ち間違えると**減点**され、正しい金額を入力し直すまで会計は完了しない

お客さんは時間経過とともに次々来店し、対応するお客さんが増えるほど来店間隔は短くなります。
**列に5人並んでしまうとゲームオーバー**です(タップで再挑戦)。

## 仕組みメモ

- 当たり判定ならぬ「正誤判定」ロジックはDOM から独立した純粋関数にしている
  - `itemsTotal` — 商品配列から合計金額を算出
  - `isCorrectAmount` — 入力値と正しい合計が一致するか判定
  - `arrivalIntervalForServed` — 対応済み人数に応じた来店間隔(ゲームが進むほど短くなる)
  - `willOverflowQueue` — 次の来店で行列が上限に達するかどうかの判定
- 商品を全部スキャンするまでテンキーは無効化される(スキャン漏れでの誤入力を防ぐ)
- 金額を間違えても即ゲームオーバーにはならず、減点の上で同じお客さんに再入力を求める
  (行列は待たせたままになるため、素早く正しく打ち直すプレッシャーが生まれる)
- 来店処理はrequestAnimationFrameベースの経過時間(dt)でタイマーを進めており、
  スキャン・入力などのユーザー操作はイベント駆動で即座に反映する構成にしている
