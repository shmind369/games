# VR MISSIONS 3D（中華娘 ver）

`ver.html`（VR MISSIONS 3D // SNEAKING）のリメイク第1弾。**プレイヤーを中華娘のモデルに**、**敵（歩哨）を中華娘に合わせて作り直した「護衛兵」のモデル**にした。ステージ・視界コーン・警報・射撃・パンチなどのゲームの中身は元のまま。

- 開く: `index.html`（3D は `vendor/` の three.js を使う。ネット接続は不要）
- 遊び方: 元のゲームと同じ（左スティック = 移動、右ドラッグ = 視点、FIRE / PUNCH）

## モデル
- **プレイヤー（中華娘）**: `assets/china_rigged.glb`（`china-walk-tps` / `side-fighter-3d` と同じもの）。歩きは `assets/walk.json`、パンチは `assets/punch.json`（右ストレート。上半身だけ重ねる）
- **敵（護衛兵）**: `assets/guard_china_rigged.glb`。濃紺の長衣（金の縁どり・金の肩当て）・赤い帯と房・黒いズボンと白底の布靴・黒髪の一つ団子に赤い鉢巻・つり目。中華娘と**同じ19ボーンの骨格・同じ初期姿勢**なので、中華娘用のモーション（`walk.json` など）がそのまま使える。パトロールは中華娘と同じ歩き、倒されると前へうつぶせに倒れる
- 護衛兵の作り方・調整: `python3 tools/make_guard.py` で `assets/guard_china_rigged.glb` を作り直せる。パーツ（色・大きさ・位置）は `tools/make_guard.py` の「パーツ」の部分を書き換える。色は頂点カラー、ゲームでは面ごとの陰影（フラットシェーディング）でローポリ風に見せている

## 元のゲームからの主な変更
- 針金のキャラ（ワイヤーフレームの箱）を、スキン付きGLBに置き換え（歩き・立ち・パンチ・倒れる動き）
- キャラ用のライトを追加（背景のワイヤーフレームは元のまま）
- 通路の幅に合わせて、キャラを 0.82 倍にした（`CHAR_SCALE`）。命中判定の高さ（`GUARD_HEIGHT`）は 1.5m に変更
- 後ろへ歩くときは、歩きを逆再生

## 視点・操作（三人称のみ・片手操作）
- **一人称（構え）視点は廃止**。カメラは常に**自機の肩越し（右肩の後ろ上）**から、**自機が向いている方向についてくる**。自機は**全身が見えて**（画面の上のほうに映る）、**前方が遠くまで見渡せる**。壁は半透明なので、壁の近くでも自機が隠れない
- スマホ縦画面を**片手**で遊べる操作（画面の下3分の1が操作エリア）:
  - **真ん中のスティック**: **上下 = 前進・後退**（後退は遅い）/ **左右 = 旋回**（右へ倒すと右へ向きを変える）。カメラは自機の向きにあわせて回る
  - **右のボタン**: **FIRE** = 自機の前方（±45°）にいる、いちばん近い敵を自動で狙って撃つ（壁ごしは狙わない）。いなければ前へまっすぐ撃つ / **PUNCH** = 近くの敵（1.1m以内）のほうを自動で向いて、無音で倒す
  - PC: W/S 前後・A/D（または Q/E）旋回、Space で発射、F でパンチ
- 上部のミラー（背後の映像）は残してある。いらなければ `index.html` の `#mirrorWrap` を消し、`main.js` の `renderMirror` を外す
- 調整用の値（`main.js`）: `CAM_BACK` / `CAM_UP` / `CAM_SHOULDER`（カメラの位置: 後ろ・上・右肩）、`CAM_PITCH`（見る角度。下向きにするほど自機が画面の上に寄る）、`CAM_FOLLOW`（向きへの追従の速さ）、`TURN_SPEED`（旋回の速さ）、`AUTO_AIM_ANGLE`、`PUNCH_RANGE`、`STICK_DEAD`
