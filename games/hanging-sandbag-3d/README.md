# hanging-sandbag-3d

物理演算テスト：吊り下げ式サンドバッグ(Three.js + Rapier Physics)

天井から吊るした硬い剛体のサンドバッグ1個を、物理エンジンだけで自然に揺らす基礎検証です。
アニメーションによる揺れは一切使っておらず、毎フレームの位置・回転は Rapier のシミュレーション結果をそのまま描画しています。

## 操作

| 操作 | 内容 |
| --- | --- |
| バッグをクリック / タップ | クリックした表面の位置に撃力を加える |
| ドラッグ | 視点を回転 |
| ホイール / ピンチ | ズーム |
| 強さ スライダー | 撃力 5〜100 N·s(既定 35) |
| 上下角 スライダー | 打撃方向を上下に傾ける(±45°) |
| 方向 | 視線方向(水平成分) / 視線方向(そのまま) / 面に垂直に押し込む |
| プリセットボタン | 正面・中央 / 右寄り / 左寄り / 側面・中央 / 上部 / 下部 をワールド方向から打つ |
| スロー | 物理時間を 1/4 倍速で進める(時間刻み自体は固定のまま) |

画面左上に状態・振れ角・自転速度・力学的エネルギー・ジョイントの接続ずれ、右上に真上から見たバッグ下端の軌跡を表示します。

## ボクサー(操作できる)

起動時は「ボクサー操作」モード(右上のボタンで「打撃テスト」の従来パネルと切り替え)。

| 操作 | スマホ | PC |
| --- | --- | --- |
| 回避 / ステップ移動 | 左下のスティック(倒し量で切り替え。下記) | 回避 = 矢印 / 移動 = WASD |
| ジャブ(左) | JAB ボタン | J / Z |
| ストレート(右) | STRAIGHT ボタン | K / X |
| 視点 | 画面ドラッグ / ピンチ | マウスドラッグ / ホイール |

- **スティックの倒し量で 待機 / 回避 / 移動 を切り替え**(`stickModes.js`)
  - 0〜15%: 待機 / 15〜35%: 小さな回避 / 35〜65%: 大きな回避 / 65〜100%: ステップ移動(倒すほど速い)
  - 回避の傾きは ver2 で約2倍、反応(補間の速さ)は入り 30 / 戻り 18 に高速化
  - 回避の深さは倒し量に応じて連続的に変わる(15% で 0.25 → 35% で 0.55 → 65% で 1.0)。保持している間は回避姿勢のまま、離すと滑らかにニュートラルへ戻る
  - 回避の向きは **相手(バッグ)基準**: 左 = ヘッドスリップ(左) / 右 = ヘッドスリップ(右) / 上(相手へ向かう)= ダッキング / 下(相手から離れる)= スウェー。
    斜めは隣どうしを混ぜる。4つの回避は `boxer.js` の `DODGES` でそれぞれ独立したポーズとして管理
  - 回避はその場で行う(足元の位置は動かない)。腰を落とすときは太もも・すね・足首を合わせて曲げ、足の裏を床に付けたまま
  - ヒステリシス: 回避は 15% で入り 12% で抜ける、移動は 65% で入り 58% で抜ける(境目で頻繁に切り替わらない)
  - 一気に大きく倒したとき(倒し量が速く変化している間)は途中の回避ゾーンで回避を出さない
  - ボクサー操作中はカメラがボクサーの背中側へ自動で回り込み、画面の上下左右 = 相手基準の前後左右 になる(手で視点を回すと2.5秒止まる)
  - 調整値: `stickModes.js` の `STICK_ZONES`、`boxer.js` の `DODGES` と `BOXER.dodgeIn / dodgeOut`
- **反復横跳びのようなステップ移動**: 構えを保ったまま、1回の跳び = **溜め**(膝を曲げて沈む 0.10秒)→ **蹴り出し**(地面を蹴って一気に跳ぶ 0.15秒。
  進む向きへ体を傾け、進む側の脚が先へ伸び、反対の脚が後ろに残る)→ **着地**(膝で受け止める 0.10秒)。スティックを倒している間は繰り返す(2回目以降は着地の沈みから
  すぐ蹴るので溜めは0.05秒)。1回の距離はスティックの倒し量で 0.22〜0.55m。体が動くのは蹴り出しの間だけなので、溜め・着地で足が床を滑らない。
  溜めの途中で離すと跳ばずにその場に残る。常にバッグの方を向く。調整値は `BOXER.hop*`・`loadKnee`・`landKnee`・`hopLean`
- **パンチでバッグが動く**: ジャブ(`assets/leftJabInPlace1.json`)/ ストレート(`assets/rightStraight.json`、体ごと踏み込む)を上半身に重ね、
  毎フレーム **グローブの実際の位置** をバッグの物理形状(円筒)と照合する。前フレームからの通り道をなぞって判定するので、速い拳でもすり抜けない。
  当たったら **その接触点に、拳の進む向きの撃力**(ジャブ 16 N·s / ストレート 30 N·s)を加える → 当てた高さ・位置で揺れ方や回転が変わる
- 届く距離の目安: バッグの中心から 0.5〜0.8m(ジャブは 0.9m まで)
- **体の当たり判定**: キネマティックのカプセル。揺れて戻ってきたバッグは体にぶつかる。ボクサーは揺れているバッグの今の位置へは踏み込まない
  (体でバッグを押してエネルギーを注ぎ込まないように)
- 調整値: `boxer.js` の `BOXER`(移動速度・歩数・弾み・脚の振り・パンチの撃力・グローブの大きさなど)
- ボクサーの身長(約1.74m)に合わせて、天井の吊り位置は 2.7m(バッグは床から 0.85〜1.85m)

## 物理モデル

```
天井(固定剛体)
  │  球面ジョイント(天井アンカー)
チェーン(動的剛体 1.5kg, 長さ 0.5m)
  │  球面ジョイント(スイベル)
サンドバッグ(動的剛体の円筒 30kg, 直径 36cm × 長さ 100cm。吊りベルト 35cm は剛体の一部)
```

- 慣性モーメントは円筒形状から自動計算(Iy = mr²/2, Ix = Iz = m(3r²+h²)/12)
- 衝撃は `applyImpulseAtPoint` で **実際の接触点** に加える。重心からのずれ r に応じて r × J のトルクが生じ、
  - 中央を打つ → 純粋な振り子運動(前後 / 左右)
  - 左右にずらして打つ → 自転(スイベルまわりの回転)
  - 上下にずらして打つ → バッグの傾き(チェーンとの二重振り子的な動き)
- 減衰: 線形 0.12 / 角 0.35(空気抵抗とスイベル摩擦の近似)。放置すると約1分で静止する
- 時間刻み 1/240 秒の固定ステップ、ソルバ反復 12 回。描画は前後ステップ間を補間
- スリープは無効(振れの途中で眠って止まるのを防ぐため。減衰のみで静止させる)
- ジョイントで繋がった物体同士の接触は無効

## 完成条件の検証

描画と同じ `physics.js` をヘッドレスで動かし、完成条件を数値で確認するスクリプトがあります。

```
node games/hanging-sandbag-3d/verify.mjs
```

```
PASS  重力で鉛直に垂れ下がる
PASS  正面衝撃→前後 / 側面衝撃→左右
PASS  衝撃位置で回転が変わる
PASS  追加衝撃で方向・振幅が変化
PASS  放置で静止(エネルギー非増加)
PASS  連打でも接続位置が維持される   (60 N·s × 120回連打でも最大ずれ 約1.3mm、通常時 0.03mm)
```

## ファイル

- `physics.js` — Rapier の物理モデル(描画非依存)
- `main.js` — Three.js 描画・入力・固定ステップループ・HUD
- `boxer.js` — ボクサー(モデル・フットワーク・回避ポーズ・パンチ・グローブとバッグの当たり判定)
- `stickModes.js` — スティックの倒し量で 待機/回避/移動 を判定(ヒステリシス付き)
- `verify.mjs` — 完成条件のヘッドレス検証
- `vendor/` — three.module.min.js, Rapier (`@dimforge/rapier3d-compat@0.14.0`、WASM 同梱版、Apache-2.0)

## 対象外(今回の範囲外)

変形・布やゴムの弾性・内部の砂の移動・破損表現・人体との衝突判定。
