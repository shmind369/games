# hanging-sandbag-3d

物理演算テスト：吊り下げ式サンドバッグ(Three.js + Rapier Physics)

天井から吊るした硬い剛体のサンドバッグ1個を、物理エンジンだけで自然に揺らす基礎検証です。
アニメーションによる揺れは一切使っておらず、毎フレームの位置・回転は Rapier のシミュレーション結果をそのまま描画しています。

## 操作

| 操作 | 内容 |
| --- | --- |
| バッグをクリック / タップ | クリックした表面の位置に撃力を加える |
| ドラッグ | 視点を回転 |
| ホイール / ピンチ | ズーム |
| 強さ スライダー | 撃力 5〜100 N·s(既定 35) |
| 上下角 スライダー | 打撃方向を上下に傾ける(±45°) |
| 方向 | 視線方向(水平成分) / 視線方向(そのまま) / 面に垂直に押し込む |
| プリセットボタン | 正面・中央 / 右寄り / 左寄り / 側面・中央 / 上部 / 下部 をワールド方向から打つ |
| スロー | 物理時間を 1/4 倍速で進める(時間刻み自体は固定のまま) |

画面左上に状態・振れ角・自転速度・力学的エネルギー・ジョイントの接続ずれ、右上に真上から見たバッグ下端の軌跡を表示します。

## タイトル画面とモード

起動するとタイトル画面(BOXING TEST)で **対戦モード / サンドバッグモード** を選ぶ。プレイ中は操作領域左上の「≡ タイトル」で戻れる。
URL に `?mode=versus` / `?mode=sandbag` を付けると直接始まる(`?test` は打撃テストのパネル)。

### 対戦モード
- 対戦相手は `assets/box_usa_rigged.glb`(USAボクサー。自機と同じ19ボーンの骨格なので、構え・ステップ・パンチの仕組みをそのまま使う)
- 相手のAI(`ai.js`): 間合い約0.74mを保つ(遠ければ詰め、近すぎれば下がり、時々横へ回り込む)。間隔をあけてジャブ・ストレート・ワンツー・フックを出す。打たれると少しひるむ
- 当たり判定(`boxer.js` の `checkBodyHit`): グローブの通り道を、相手の **頭(あご〜頭頂のカプセル)** と **腹** と照合。回避すると頭が実際に動くので、
  ダッキング・スウェーは相手のパンチをかわせる(スリップは片方の手のパンチだけかわせる)
- ダメージ: ジャブ 6 / ストレート 10 / フック 9(頭は ×1.3、コンビネーションの2発目以降は ×0.85)。体力 100、0 で KO(後ろへ倒れる)→ 結果画面(もう一度 / タイトルへ)
- 被弾すると頭・上体が打たれた向きへ弾かれる。画面上端に体力バー(YOU / USA)
- 対戦中はサンドバッグとその物理は止めている

## 会場(ボクシングリング)

`arena.js`。すべて箱・円柱と画面上で描いた模様で作っていて、外部ファイルは増やしていない(コード約9KB)。
- リング: ロープの内側 6m 四方、高さ 1m の台(マット面 = 床 y=0)、エプロン、コーナーポスト(赤・青・白のパッド)、ロープ4段
  (高さは下から 0.29 / 0.58 / 0.86 / 1.15m。最上段が自機の脇の下あたり、残りはマットとの間に等間隔。ポストとパッドもロープに合わせる)
- **遮蔽物の透過**: カメラと自機の間に入って自機を隠しているロープ・コーナーポスト・パッドだけを、滑らかに半透明(不透明度 22%)にする。
  自機の画面上の範囲(頭・胴・手足を投影した四角)と各物体の線分の投影が重なり、かつ自機よりカメラに近いときだけ透過する
  (ロープに触れているだけ・自機の後ろにあるだけでは透過しない)。薄くなるのは約0.3秒、戻るのは約0.6秒の補間。
  戻りきったら元のマテリアル設定に復元する。見た目だけで当たり判定は変えない。バッグなど他の物体には影響しない。
  調整値は `arena.js` の `FADE`
- サンドバッグはリング中央の照明トラスの梁から吊る(吊り位置の高さ 2.7m は物理と同じ)
- まわりは暗い会場、トラス四隅のスポットライト、客席の人影
- ボクサーはロープ際で止まる(`BOXER.ringHalf`。リングの外へは出ない)

## ボクサー(操作できる)

起動時は「ボクサー操作」モード。画面は **上 = プレイ領域 / 下 = 操作領域** に分け、上部のナビゲーション(数値表示・軌跡マップ・モード切替)は出さない。
操作領域は画面下の中央に **移動パッド(168px。以前の1.2倍)**、その左右に JAB / STRAIGHT。打撃テストの従来パネルは URL に `?test` を付けると開ける。

| 操作 | スマホ | PC |
| --- | --- | --- |
| 回避 / ステップ移動 | 下中央の移動パッド(倒し量で切り替え。下記) | 回避 = 矢印 / 移動 = WASD |
| ジャブ(左) | JAB ボタン | J / Z |
| ストレート(右) | STRAIGHT ボタン | K / X |
| 視点 | 画面ドラッグ / ピンチ | マウスドラッグ / ホイール |

- **スティックの倒し量で 待機 / 回避 / 移動 を切り替え**(`stickModes.js`)
  - 0〜12%: 待機 / 12〜42%: 小さな回避 / 42〜82%: 大きな回避 / 82〜100%: ステップ移動(倒すほど速い)
  - 回避の傾きは ver2 で約2倍、反応(補間の速さ)は入り 30 / 戻り 18 に高速化
  - 回避の深さは倒し量に応じて連続的に変わる(12% で 0.25 → 42% で 0.55 → 82% で 1.0)。保持している間は回避姿勢のまま、離すと滑らかにニュートラルへ戻る
  - 回避の向きは **相手(バッグ)基準**: 左 = ヘッドスリップ(左) / 右 = ヘッドスリップ(右) / 上(相手へ向かう)= ダッキング / 下(相手から離れる)= スウェー。
    斜めは隣どうしを混ぜる。4つの回避は `boxer.js` の `DODGES` でそれぞれ独立したポーズとして管理
  - 回避はその場で行う(足元の位置は動かない)。腰を落とすときは太もも・すね・足首を合わせて曲げ、足の裏を床に付けたまま
  - ヒステリシス: 回避は 12% で入り 9% で抜ける、移動は 82% で入り 75% で抜ける(境目で頻繁に切り替わらない)
  - 一気に大きく倒したとき(倒し量が速く変化している間)は途中の回避ゾーンで回避を出さない
  - 回避の割り当てはスティックの向きそのまま(上 = ダッキング / 下 = スウェー / 左右 = スリップ)。カメラの向きには関係しない
- **カメラ**: ボクサー操作中は、自機とバッグの全身が常に映る横寄りの構図に自動で追従する。自機の右斜め後ろ(真後ろから約57°)から
  2人の中間を見て、自機が左・バッグが右に映る。距離は2人の間隔と画面の幅から決める(離れるほど引く)。手で視点を回すと2.5秒止まる。
  調整値は `main.js` の `CAM_SIDE_ANGLE`・`CAM_PITCH`・`CAM_MARGIN`・`CAM_HEIGHT_HALF`・`CAM_MIN_DIST`
  - 調整値: `stickModes.js` の `STICK_ZONES`、`boxer.js` の `DODGES` と `BOXER.dodgeIn / dodgeOut`
- **コンビネーション(最大5発)**: パンチの途中で次のボタンを押すと予約され、今のパンチが伸びきった直後に戻りを切り上げて次を打つ。
  左右交互ほど速くつながる(ジャブ→ストレートは約0.17秒、同じ手を続けると少し遅い)。2発目以降は少し速く(×1.15)、
  1発ごとにバッグへ 0.14m 詰め、撃力はやや軽い(×0.75。バッグが離れすぎて次が空振りしないように)。
  切り替えは前のパンチを0.1秒かけて薄くしながら重ねるので姿勢が飛ばない。5発打ったら、構えに戻るまで次の入力は受け付けない。
  画面には「コンビネーション n 発目」と出る。調整値は `boxer.js` の `BOXER.combo*`・`cancelAt`・`sameHandExtra`
- **回避からのカウンター(移動パッドを使った攻撃のテスト)**: 左右のスリップ中(回避の重み 0.3 以上)にスティックから **指を離した瞬間** にパンチを打つ。
  スティックの角度で打ち分け:
  | 離したときのスティック | 左 | 右 |
  | --- | --- | --- |
  | 真横(水平から 22.5° 未満) | 左ジャブ | 右ストレート |
  | 斜め 45°(22.5〜67.5°。上でも下でも) | 左フック | 右フック |
  | それより縦(ダッキング・スウェー寄り) | 出さない | 出さない |

  避けた姿勢からそのまま打ち、回避は補間でニュートラルへ戻る。PC は矢印キーで回避 → キーを離したとき。割り当ては `main.js` の `RELEASE_COUNTERS`、
  角度の境目は `COUNTER_HOOK_FROM / TO`
- **フック**(クリップが無いので手続きで作成。`boxer.js` の `HOOK`): 振りかぶりで肘を外へ引き、肘を肩の高さに張ったまま拳を外から内へ水平に振り抜く。
  腰と上体を回し、0.33m 踏み込んで体ごと打つ(構えの距離 0.78m から届く)。撃力 左 26 / 右 28 N·s。当たり判定はジャブ・ストレートと同じくグローブの実位置
- **反復横跳びのようなステップ移動**: 構えを保ったまま、1回の跳び = **溜め**(膝を曲げて沈む 0.10秒)→ **蹴り出し**(地面を蹴って一気に跳ぶ 0.15秒。
  進む向きへ体を傾け、進む側の脚が先へ伸び、反対の脚が後ろに残る)→ **着地**(膝で受け止める 0.10秒)。スティックを倒している間は繰り返す(2回目以降は着地の沈みから
  すぐ蹴るので溜めは0.05秒)。1回の距離はスティックの倒し量で 0.22〜0.55m。体が動くのは蹴り出しの間だけなので、溜め・着地で足が床を滑らない。
  溜めの途中で離すと跳ばずにその場に残る。常にバッグの方を向く。調整値は `BOXER.hop*`・`loadKnee`・`landKnee`・`hopLean`
- **パンチでバッグが動く**: ジャブ(`assets/leftJabInPlace1.json`)/ ストレート(`assets/rightStraight.json`、体ごと踏み込む)を上半身に重ね、
  毎フレーム **グローブの実際の位置** をバッグの物理形状(円筒)と照合する。前フレームからの通り道をなぞって判定するので、速い拳でもすり抜けない。
  当たったら **その接触点に、拳の進む向きの撃力**(ジャブ 16 N·s / ストレート 30 N·s)を加える → 当てた高さ・位置で揺れ方や回転が変わる
- 届く距離の目安: バッグの中心から 0.5〜0.8m(ジャブは 0.9m まで)
- **体の当たり判定**: キネマティックのカプセル。揺れて戻ってきたバッグは体にぶつかる。ボクサーは揺れているバッグの今の位置へは踏み込まない
  (体でバッグを押してエネルギーを注ぎ込まないように)
- 調整値: `boxer.js` の `BOXER`(移動速度・歩数・弾み・脚の振り・パンチの撃力・グローブの大きさなど)
- ボクサーの身長(約1.74m)に合わせて、天井の吊り位置は 2.7m(バッグは床から 0.85〜1.85m)

## 効果音

音声ファイルは使わず、WebAudio でその場で合成する(`sound.js`)。操作領域の右上の 🔊 / 🔇 でオン/オフ(端末に保存)。iOS は最初のタッチで音が有効になる。

| 音 | いつ |
| --- | --- |
| 「ドスッ」+ 革の「パン」 | パンチ(または打撃テストのタップ)がバッグに当たったとき。撃力が強いほど重く大きい。フック・ストレートはジャブより重い |
| 風切り音(控えめ) | パンチを打ち出したとき(ジャブは短く、フックは長め) |

チェーンの「チャリッ」・ステップの足音・回避の風切り音は一旦なし(`sound.js` の `CHAIN_SOUND` / `STEP_SOUND` / `DODGE_SOUND` を `true` にすると鳴る)。パンチの風切り音は控えめ(`SWING_GAIN`)。

## 物理モデル

```
天井(固定剛体)
  │  球面ジョイント(天井アンカー)
チェーン(動的剛体 1.5kg, 長さ 0.5m)
  │  球面ジョイント(スイベル)
サンドバッグ(動的剛体の円筒 30kg, 直径 36cm × 長さ 100cm。吊りベルト 35cm は剛体の一部)
```

- 慣性モーメントは円筒形状から自動計算(Iy = mr²/2, Ix = Iz = m(3r²+h²)/12)
- 衝撃は `applyImpulseAtPoint` で **実際の接触点** に加える。重心からのずれ r に応じて r × J のトルクが生じ、
  - 中央を打つ → 純粋な振り子運動(前後 / 左右)
  - 左右にずらして打つ → 自転(スイベルまわりの回転)
  - 上下にずらして打つ → バッグの傾き(チェーンとの二重振り子的な動き)
- 減衰: 線形 0.12 / 角 0.35(空気抵抗とスイベル摩擦の近似)。放置すると約1分で静止する
- 時間刻み 1/240 秒の固定ステップ、ソルバ反復 12 回。描画は前後ステップ間を補間
- スリープは無効(振れの途中で眠って止まるのを防ぐため。減衰のみで静止させる)
- ジョイントで繋がった物体同士の接触は無効

## 完成条件の検証

描画と同じ `physics.js` をヘッドレスで動かし、完成条件を数値で確認するスクリプトがあります。

```
node games/hanging-sandbag-3d/verify.mjs
```

```
PASS  重力で鉛直に垂れ下がる
PASS  正面衝撃→前後 / 側面衝撃→左右
PASS  衝撃位置で回転が変わる
PASS  追加衝撃で方向・振幅が変化
PASS  放置で静止(エネルギー非増加)
PASS  連打でも接続位置が維持される   (60 N·s × 120回連打でも最大ずれ 約1.3mm、通常時 0.03mm)
```

## ファイル

- `physics.js` — Rapier の物理モデル(描画非依存)
- `main.js` — Three.js 描画・入力・固定ステップループ・HUD
- `boxer.js` — ボクサー(モデル・フットワーク・回避ポーズ・パンチ・グローブとバッグの当たり判定)
- `stickModes.js` — スティックの倒し量で 待機/回避/移動 を判定(ヒステリシス付き)
- `sound.js` — 効果音(WebAudio で合成)
- `arena.js` — ボクシングリングの会場(見た目)
- `ai.js` — 対戦相手のAI
- `verify.mjs` — 完成条件のヘッドレス検証
- `vendor/` — three.module.min.js, Rapier (`@dimforge/rapier3d-compat@0.14.0`、WASM 同梱版、Apache-2.0)

## 対象外(今回の範囲外)

変形・布やゴムの弾性・内部の砂の移動・破損表現・人体との衝突判定。
