# Kung-Fu Versus 3D

中華娘(プレイヤー)でUSAボクサー(CPU)と戦う、体力ゲージ制・奥行き移動ありのサイドビュー3D格闘ゲームです(Three.js製)。
スマホ縦画面向け(PCのキーボードでも遊べます)。

## ルール

- 体力100。相手の体力を0にすると **K.O.**。1ラウンド60秒で、時間切れは体力の多いほうが勝ち
- **2ラウンド先取**で勝利(最大5ラウンド)。試合が終わると「もう一度」で最初から
- 攻撃には **上段 / 中段 / 下段** がある
  - **立ちガード**(スティック←): 上段・中段を防ぐ。下段は当たる
  - **しゃがみ**(スティック↓長押し): 上段は頭の上を通ってかわせる。下段を防ぐ。中段は当たる
- 相手の技の出始め(予備動作・攻撃中)に当てると **COUNTER**(ダメージ1.3倍)
- 技の途中でボタンを押しておくと、次の技へつながる(**コンボ**。最大4発。2発目以降は少しダメージ減)

## 操作

| 操作 | スマホ | PC |
|---|---|---|
| 前進 / 後退(後退中は立ちガード) | スティック → / ← | D / A(→ / ←) |
| 奥へ横移動(押している間) | スティック ↑ | W(↑) |
| 手前へ横ステップ | スティック ↓ を短く | S(↓)を短く |
| しゃがみ | スティック ↓ 長押し | S(↓)長押し |
| ジャブ(上段・6) | 左上ボタン | U |
| ストレート(中段・10) | 右上ボタン | I |
| ローキック(下段・9) | 左下ボタン | J |
| ハイキック(上段・17、出が遅い) | 右下ボタン | K |

- 横移動は相手との距離を保ったまま弧を描く(回り込める)。**カメラは常に2人を結ぶ線の真横**から映すので、回り込むとカメラも回る(プレイヤーは常に画面の左)
- CPUの飛び込み攻撃は、予備動作の始めに向きと距離が決まる。予備動作を見てから横移動・後退すればかわせる

## CPU

- 間合いまで近づき、予備動作のあと飛び込んで攻撃する: **飛び込みジャブ**(上段・のけぞる構え)/ **ボディストレート**(中段・腰を落とす)/ **足払いフック**(下段・深く沈む)。技のあとは隙がある
- プレイヤーが技を出すと、35%でガード(上段・中段なら立ち、下段ならしゃがみ。4回に1回は読み違える)、12%で横ステップでかわす
- `?ai=0` を付けて開くと、CPUが何もしない(練習・確認用)

## 仕組みメモ

- モデル: `assets/china_rigged.glb`(プレイヤー)/ `assets/box_usa_rigged.glb`(CPU)
- モーション(humanoid-gltf-exporter / side-fighter-3d と同じJSON形式): 構え `fightIdleUsa` / ステップ `stepForward`・`stepSide` / ジャブ `leftPunch1` / ストレート `rightStraight` / ローキック `rightLowKick` / ハイキック `rightHighKick`(8キーフレーム版) / CPU `cpuJab`・`cpuBodyStraight`・`cpuLowHook`
- 技の性能(上中下段・ダメージ・当たる区間・ノックバック・硬直・コンボ受付)は `main.js` の `MOVES` の表で調整できる
- 当たり判定: 技の当たる区間の間、攻撃している手足の球と相手の体の球(頭・胸・腰・もも・すね)が重なったらヒット(1回の技で1回)
- しゃがみ・ガード・被弾の反応・CPUの予備動作は、構えのポーズに回転を重ねて作っている(`CROUCH` / `GUARD` / `REACT` / `tell`)
- KO時はスローモーション(0.3倍・約0.9秒)になり、負けた側が後ろへ倒れる

## テスト結果(Playwright)

- 4つの技すべてが近距離でヒット(ダメージ 6 / 10 / 9 / 17)
- CPUの上段・中段・下段 × 立ったまま / 立ちガード / しゃがみ:
  - 立ったまま: 3つとも被弾
  - 立ちガード: 上段・中段はガード、下段は被弾
  - しゃがみ: 上段はかわす、中段は被弾、下段はガード
- 横移動(↑長押し)で相手との距離1.4mを保ったまま約90°回り込み、カメラも約90°回る / ↓を短く離すと手前へ横ステップ / CPUの飛び込みジャブを予備動作中の横移動でかわせる
- KO → スローモーション → 勝ちマーク → 次のラウンド(体力が戻る)へ進む
- CPUが自分で近づいて攻撃し、ガードしないプレイヤーの体力が減っていく / エラーなし
